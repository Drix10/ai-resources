# Contributing

Thanks for helping. The digests in this repo are written by the [ai-resources-pipeline](https://github.com/Drix10/ai-resources-pipeline) and regenerated often, so most help comes through issues rather than pull requests against the Markdown files.

## Ways to help

| You want to… | Do this |
| --- | --- |
| Suggest an X account, list or site to follow | Open a [Suggest a source](https://github.com/Drix10/ai-resources/issues/new?template=suggest-source.yml) issue. Say which category it belongs in and link two or three recent posts that show why. |
| Report a wrong number, name or link | Open a [Report an error](https://github.com/Drix10/ai-resources/issues/new?template=report-error.yml) issue with the digest link and what is wrong. Wrong facts are fixed first. |
| Propose a new category | Open a [Suggest a source](https://github.com/Drix10/ai-resources/issues/new?template=suggest-source.yml) issue, pick "New category", and list 5+ accounts that would feed it. |
| Improve the pipeline (fact checks, formatting, new outputs) | Contribute to [ai-resources-pipeline](https://github.com/Drix10/ai-resources-pipeline). Issues labelled `good first issue` there are the easiest start. |
| Fix the README or these docs | A pull request is welcome. Edit only the text **above** the `## 📚 Resource Categories` heading; everything below it is regenerated on every run. |

## What gets in

A source is a good fit when it:

- posts concrete things (releases, numbers, papers, code, postmortems) more often than opinions;
- is the original author, not a repost or aggregator account;
- fits one of the [41 categories](README.md#-resource-categories), or enough sources exist to justify a new one.

Paid placements are not accepted. If you suggest your own account or product, say so in the issue; it is judged the same way.

## Pull requests to digest files

Hand edits to `resources-NNN.md` files are accepted only to fix a factual error or a broken link, and only with a link to the source that shows the correction. Keep the existing structure (headline, summary, Key Points, Resources).

## Conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
