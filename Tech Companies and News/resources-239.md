### 🚀 Eon Yukon launch: serverless engine at 1M events/sec

Eon Yukon is a new serverless data engine that moves data from ingestion to serving in a continuous flow. It claims sub-millisecond latency via a Redis-compatible API and SQL/Spark compatible queries. The benchmark shows 1M events/sec with 4× less compute than Spark and 7× less than Flink.

Key Points:

- **Launch**: Eon Yukon serverless data engine built to replace traditional Spark and Flink pipelines.

- **Benchmark**: 1M events/sec throughput using 4x less compute than Spark and 7x less than Flink.

### 🤖 RAMBO air-gapped PC data exfiltration 1000 bits per second

RAMBO turns a computer’s RAM into a radio transmitter, leaking data at 1000 bits per second. Malware drives the memory bus to emit on/off radio signals. Reception works up to 7 meters with a software-defined radio and off-the-shelf antenna.

Key Points:

- **Data rate**: 1000 bits per second (≈128 bytes per second).

- **Reception range**: reliable up to 7 meters, fast transmissions top out at about 3 meters.
