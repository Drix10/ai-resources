### 🤖 GitHub Actions workflow lockfiles enter public preview

GitHub Actions workflow dependency lockfiles are now in public preview for multiple GitHub plans. Lockfiles keep workflow runs tied to the exact commits you locked, preventing unexpected code changes from moved tags or branches. The Require lockfile policy is also available in public preview.

Key Points:

- Public preview includes Enterprise Cloud, Enterprise Cloud with data residency, Team, and Free plans.

- The gh actions-lock CLI extension can generate .github/workflows/actions.lock with reviewable commits for actions and transitive dependencies.
