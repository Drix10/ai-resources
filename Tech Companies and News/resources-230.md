### 🚀 Brewlet introduced at Devoxx Belgium

Brewlet was announced today at Devoxx Belgium. It runs Java on Kubernetes without bundling a JDK in each app image. Users ship only JAR files and manage JDKs on the nodes.

Key Points:

- **Launch**: Introduced today at Devoxx Belgium

- **Feature**: Runs Java on Kubernetes without bundling a JDK in every app image

### 🤖 Framework Desktop batch availability update

Framework announced that Batch 2 of the 192 Framework Desktop is sold out. They will wait for confirmed shipments and pricing on additional memory before opening more batches. The 128 configuration remains in stock.

Key Points:

- Batch 2 of the 192 Framework Desktop is sold out
