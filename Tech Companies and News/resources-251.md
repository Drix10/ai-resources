### 🤖 Cuttlefish macOS Apple silicon port released on GitHub

Cuttlefish, the Android Open Source Project virtual-device framework, now runs natively on macOS with Apple silicon. Meta published patches, tools, scripts, manifests and docs under Apache 2.0. The repository is publish-only, does not accept pull requests, and requires a case-sensitive volume for AOSP filenames.

Key Points:

- Patch set adds native macOS and Apple silicon support for Cuttlefish.

- Repository warns to use a case-sensitive volume or the build will fail.
