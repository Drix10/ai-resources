### 🚨 Linux server MPTCP vulnerability leads to takeover

Linux server MPTCP vulnerability allows complete takeover of any unpatched Linux server with a single internet-exposed TCP port. The claim highlights default MPTCP activation in many Go web servers.

Key Points:

- ANY unpatched Linux server with even a single TCP port exposed to the internet is vulnerable to complete takeover.

- MPTCP is active by default for many Go web servers.
