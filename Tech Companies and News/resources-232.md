### 🚀 WindHawk dark mode mod for Windows 11 released

WindHawk dark mode mod for Windows 11 provides a more complete, cohesive dark theme. It fixes property dialogs, removes white flashes before windows load, and enforces Segoe UI across the UI.

Key Points:

- Mod addresses property dialogs not feeling like they belong in dark mode.

- Mod eliminates white background flashing before windows or file pickers load in dark mode.
