### 🤖 MobileVISTA announced for pose generalization from a single base pose

MobileVISTA is introduced as a follow‑up to VISTA. It augments demos in the image space to improve robustness to robot base position changes. The claim is that policies trained from one base pose can work from many poses despite base pose errors of a few centimeters.

Key Points:

- MobileVISTA follows previous work VISTA.

- It aims to collect demos at one base pose and obtain a policy that works from many poses.

### 🤖 New GPU DSL built on OxCaml matches cuBLAS on H100

A new GPU domain-specific language is being started, using OxCaml’s high-performance programming model. Version 0 of its compiler can express an 8192³ TF32 GEMM in 100 lines of OCaml and matches cuBLAS performance on an H100.

Key Points:

- **DSL**: GPU DSL built on OxCaml’s high-performance programming model.

- **Benchmark**: 8192³ TF32 GEMM in 100 OCaml lines matches cuBLAS on an H100.
