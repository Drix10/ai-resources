### 🤖 DefFlow – goal-conditioned 3D world action modelling announced

DefFlow is a goal-conditioned 3D World Action Modelling approach that learns to manipulate deformable objects into diverse goal shapes using 3D point flows. It targets ropes, granular objects, and cloth for precise 3D shape control.

Key Points:

- **DefFlow**: goal-conditioned 3D World Action Modelling approach

### 🤖 Agensi – Skill Marketplace for AI Agents Launches with 18,000+ Skills
