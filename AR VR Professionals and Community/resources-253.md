### 🤖 Google Playground AI Game Builder announced

Google Playground is a browser-based platform that uses AI to let users create games without coding. It offers a conversational interface to design, test, and adjust game elements directly. The service is currently limited to US residents and will later integrate Unity Spark for additional capabilities.

Key Points:

- **Launch**: Google Playground enables AI-driven, no‑code game creation in the browser.

- **Future integration**: Unity Spark will be added to provide Unity runtime features.

### 🚀 ElevenLabs launches Eleven v4 voice model

ElevenLabs introduced the Eleven v4 model. It can create any voice from a text prompt or clone a voice from a single audio file. The model also supports delivery tags for whispers, laughs, and attitude.

Key Points:

- **Model**: Eleven v4 can design voices from text prompts.

- **Feature**: Clone voices from a single audio file and use tags for delivery.
