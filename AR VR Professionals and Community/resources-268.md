### 🤖 3d-tiles-renderer-3tz adds .3tz support to renderer

3d-tiles-renderer-3tz is a plugin for 3DTilesRendererJS that reads a 3D Tiles tileset directly from a .3tz archive using HTTP Range requests. It works with files from URLs or browser file inputs and requires no unpacking.

Key Points:

- Reads a .3tz archive by requesting the last 256KB to obtain the central directory.

- For archives with a central directory over 16MB, uses the @3dtilesIndex1@ index and binary search to locate tiles.

### 🤖 3dtiled-to-3dtiles converts tiled 3D data to OGC 3D Tiles 1.1

3dtiled-to-3dtiles is a Node.js SDK/CLI that converts tiled point clouds, meshes, and Gaussian splats into OGC 3D Tiles 1.1. It also includes a live streaming middleware that serves 3D Tiles directly from source URLs without pre-conversion. The project provides Docker containerization and a documentation site.

Key Points:

- Converts tiled formats (COPC, Potree, I3S, stream-SOG, LCC, RAD, 3MX, GeoSplats, …) to OGC 3D Tiles 1.1.

- Live streaming server can point at a source URL and serve a 3D Tiles tileset with configurable caching (none | hierarchy | all).

- [Original post](https://x.com/berttemme/status/2119344155109285909)
