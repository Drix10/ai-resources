### 📊 Pangram bounty $500 reward for 750-word pre-2020 text flagged ≥75% AI

Pangram offers a USD $500 reward for the first pre-2020 human-written text of at least 750 consecutive words that the latest Pangram flags as 75% or more AI generated. The author spent $180 checking 599 pre-2020 texts and found zero false positives.

Key Points:

- $180 spent checking pre-2020 sources.

- 599 texts examined, 285 from Africa, false positive rate zero.

- No text scored above 75% AI; none scored above 0% AI.

- **Reward**: $500 for a 750-word pre-2020 text flagged ≥75% AI.

### 🤖 The End of Harness Engineering paper proposes self-optimizing agent harness

The End of Harness Engineering paper suggests that the infrastructure around AI agents can be improved automatically. A 4-billion-parameter model examines system failures, proposes eight changes, and keeps only the change that improves results. Human work shifts to designing tests and success criteria.

Key Points:

- 4-billion-parameter model examines the system’s failures and errors.

- Proposes eight different changes to improve performance.

- Each change is evaluated using a set of questions and tests.

- Only the change that actually delivers better results remains.
