### 🤖 Lance live demo: 8.2M Dutch parcels (5.5GB) with GeoArrow + R-Tree

Lance live demo shows 8.2M Dutch parcels (5.5GB) using GeoArrow and an R-Tree, queried from blob storage in a static MapLibre viewer. Improvement needed: add browser GeoArrow polygon support so the extra centroid/WKB copies can go.

Key Points:

- 8.2M Dutch parcels totaling 5.5GB were demonstrated.

- Data is queried from blob storage with GeoArrow + R-Tree in a static MapLibre viewer.
