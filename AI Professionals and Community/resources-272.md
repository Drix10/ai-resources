### 🤖 Mage 4B agent released, scores 66% on OSWorld-Verified

Mage is a 4B open-weight computer-use agent that scores 66% on OSWorld-Verified, compared to 72.4% for humans. It completes a spreadsheet task in 39 seconds, while Qwen3.6-27B takes nearly 10 minutes when limited to clicking.

Key Points:

- **Release**: Microsoft released Mage, a 4B open-weight computer-use agent.

### 🤖 Qwenputer Qwen3.5-4B with RISC-V CPU inside weights

Qwenputer runs Qwen3.5-4B with a full RISC-V CPU inside its weights, using Gated DeltaNet layers as RAM. On DeepMind math it achieves 97.5–100% accuracy, compared to 55–90% base and 95–100% with a Python tool.

Key Points:

- **CPU**: Qwen3.5-4B contains a full RISC-V CPU inside its weights, using Gated DeltaNet layers as RAM.

- **Runtime**: It runs C and MicroPython in its forward passes, no external runtime.

- **Benchmark**: DeepMind math results are 97.5–100% accuracy, versus base 55–90% and base + Python tool 95–100%.
