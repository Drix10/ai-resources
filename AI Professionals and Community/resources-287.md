### 🤖 Inkling-2-Mini runs 344k context on RTX 3090

Inkling-2-Mini achieves up to 344k context on an RTX 3090 with Maya backend, delivering about 100 tokens per second on low context and over 50 tokens per second on 128k context. It outperforms Qwen 27b at q4 precision and is described as a poor person’s Deepseek-v4.1-Flash-1017.

Key Points:

- **Speed**: ~100 tok/s for low context, >50 tok/s for 128k context

- **Context length**: up to 344k tokens, still >40 tok/s decode

### 🚀 DLMST deterministic linear time MST algorithm

DLMST presents a deterministic linear time algorithm for the minimum spanning tree problem, the first such improvement since Chazelle 2000. The work shows deterministic comparison complexity of MST is linear, and uses the Pettie-Ramachandran reduction to achieve linear time.

Key Points:

- Deterministic linear time algorithm for minimum spanning tree.

- First improvement since Chazelle (JACM 2000) using Pettie and Ramachandran’s reduction.
