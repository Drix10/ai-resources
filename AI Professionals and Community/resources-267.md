### 🤖 Contact-UAN – 20% lower torque, 43% lower force error

Contact-UAN adds a residual correction to humanoid actuator commands, achieving 20% lower running torque and 43% lower force-tracking error using only 6.5 min of walking data. It learns the actuator residual from onboard proprioception without torque sensors or motion capture.

Key Points:

- **Torque reduction**: 20% lower running torque.

- **Force error reduction**: 43% lower force-tracking error.

### 🤖 Mirror Rust agent core adds python TUI and HTTP API

Mirror is a Rust agent core with a python TUI using an RPC. It can also run headless behind an HTTP API. Every session is a single append-only log.

Key Points:

- Rust agent core with python TUI using RPC
