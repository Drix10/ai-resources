### 📊 Open 27B model post-training stack lifts GitHub task score

Open 27B model trained on their data gained 12.2 points on held-out GitHub computer-use tasks, rising from 35.6% to 47.8%. They built an open post-training stack to measure RL task quality.

Key Points:

- Open 27B model gained 12.2 points on held-out GitHub computer-use tasks, from 35.6% to 47.8%.

- Built an open post-training stack to measure RL task quality.

### 🤖 DreamFAR announced world model trained from robot data

DreamFAR is a world model trained from scratch using only robot data, without internet pretraining. It supports real-time teleoperation, minutes of long-horizon rollout, and generalization across 1,000+ tasks.

Key Points:

- Trained from scratch using only robot data, without internet pretraining

- Generalizes across 1,000+ tasks

### 🤖 SwarmChat library released for multi-agent coordination

SwarmChat is a messaging library for agents that lets them communicate, coordinate and logs interactions in a Slack-like app. Performance is said to climb quickly when agents use SwarmChat, and it can be installed with pip install swarmchat.

Key Points:

- **Installation**: pip install swarmchat

- Interactions recorded in a human-readable Slack-like app
