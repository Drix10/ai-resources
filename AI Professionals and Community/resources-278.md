### 🤖 Agents Are Going Async adds async subagents for background tasks

Agents Are Going Async introduces async subagents that let an orchestrator stay responsive while long tasks run in background workers. The orchestrator manages subagents with five tools and can receive notifications when tasks finish. Async subagents are available in Deep Agents for Python and JavaScript and in Managed Deep Agents via a single async field.

Key Points:

- start_async_task launches a subagent on its own thread and returns immediately.

- check_async_task retrieves a task’s status and result once it finishes.

### 📊 Instruction tuning semantic diversity loss, annotation-anchored training proposed

Instruction tuning reduces semantic diversity, especially in larger models. A new method called annotation-anchored training makes the semantic plan explicit to preserve diversity. The approach trains short tags during pretraining and updates response generation during instruction tuning, sampling a plan at generation time.

Key Points:

- Instruction tuning makes outputs less varied in meaning, more pronounced as models grow.

- Annotation-anchored training adds explicit short tags describing content and samples a plan before generating a response.
