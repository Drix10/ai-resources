### 🤖 Hutter prize text compression gains 10% via transformer overfitting

Hutter prize text compression saw ~10% improvement by training a small transformer on the target data and including its weight cost in the loss. The approach mirrors earlier video compression work that overfitted a pre-trained model on a single video using a spike-and-slab prior for weight deltas. Recent entries such as fx2-cmix-transformer, zmix, cmix-neif-beehive, cmix-neif 2.0, tufazip, and DNA-4 all use variants of weight-aware training or online adaptation.

Key Points:

- 10% progress on Hutter prize achieved by overfitting a small transformer and accounting for weight size in the coding loss.

- Prior video compression experiment overfitted a discrete-latent AE on one video with a loss = weight-delta coding cost + data likelihood, using a spike-and-slab prior.

### 🤖 How VLMs Plan What's Next – pointer planning in VLMs

How VLMs Plan What's Next shows that vision-language transformers create pointers to image regions before generating each answer token. The plan consists of pointers and progress notes that are passed through specific attention heads.

Key Points:

- Bind heads match the shape token to the picture and create a pointer to each matching panel.

- Relay heads carry that pointer to the token where the answer will be written.

- Gaze heads follow the pointer back to the image and read the content.
