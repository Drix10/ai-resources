### 🤖 Hy4-flash Uncensored on RTX 3090 – 262K context, 251 tok/s

Hy4-flash Uncensored runs Tencent 220B MoE with full 262,144 token context and vision on RTX 3090 rigs. It reaches up to 251 tokens per second on four 3090 cards and 68 tok/s on a single card. The release includes GGUF trunks, a 4MB refusal-direction vector, and scripts for runtime abliteration.

Key Points:

- 4-GPU decode speed averages 223 tok/s in a 50K-token coding session, peaking at 251 tok/s.

- Runtime abliteration uses a 4MB file to project refusal directions; refusals drop from 139/146 to 32/146 on AdvBench + JailbreakBench with thinking off.
