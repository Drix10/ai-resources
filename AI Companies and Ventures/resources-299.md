### 📊 Claude Dreaming boosts wiki accuracy to 48%

Claude’s offline “dreaming” raised wiki-only accuracy from 13% to 48% after 128 sessions. With search, accuracy reached 61%, versus 53% for search alone.

Key Points:

- Dreaming sessions increased wiki-only accuracy from 13% (2 sessions) to 48% (128 sessions).

- Wiki-plus-search accuracy rose to 61%, compared with 53% for search alone.

### 🚨 Claude Code Settings Leak 1,122 repos with secrets

Claude Code’s “don’t ask again” button saved approved shell commands, including passwords, in .claude/settings.local.json. Apiiro found 1,122 public repositories containing that file with a total of 1,379 distinct secrets.

Key Points:

- “don’t ask again” saves the exact approved Bash command word-for-word, password included, in .claude/settings.local.json.

- Apiiro identified 1,122 public copies of the file holding at least one secret, amounting to 1,379 distinct secret values.

### 🤖 Geyser – bridge lets Bedrock join Java servers

Geyser is a bridge and proxy that lets Bedrock Edition players join Java Edition servers by translating network packets. Some behavior remains unsupported because the editions work differently. The project lists supported Bedrock versions 26.40-26.62 and Java version 26.3.

Key Points:

- Bridge and proxy enabling Bedrock players on Java servers.

- Supports Bedrock 26.40-26.62 and Java 26.3.
