### 🤖 Muse Spark Open release with 816B parameters

Muse Spark Open is announced as the most capable US open-weight model to date, featuring 816B total and 42B active parameters. It supports a 1M token context window and native multimodal input across text, image, video, and audio.

Key Points:

- **Parameters**: 816B total / 42B active

- **Context window**: 1M tokens

- **Multimodal**: text, image, video, audio

- **Target use**: coding and agentic work, long-horizon tasks, complex software engineering, multi-step reasoning
