### 🤖 JUWEL Sapphire custom 72B model BF16 weights released

JUWEL Sapphire is an image-text-to-text model with 72B parameters and BF16 weights. The repository mirrors the public Cloudflare R2 release and provides safetensors shards. Loading uses Hugging Face AutoModelForImageTextToText and AutoProcessor with automatic dtype and device mapping.

Key Points:

- **Parameters**: 72,365,256,944 BF16 weights.

- **Architecture**: Qwen3VLForConditionalGeneration with 144 text layers and a 27-layer vision tower.
