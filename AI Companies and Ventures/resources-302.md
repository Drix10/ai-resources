### 🤖 Raft Artifacts now available to all users

Raft announces that Artifacts are now enabled for every user. Agents can generate pages, reports and PDFs and produce updated versions when comments are added.

Key Points:

- Artifacts are now on for everyone in Raft.

- Agents make pages, reports and PDFs; opening one beside the chat, commenting on any line, and the agent returns a new version.

### 🤖 Gazebo Sim – open source robotics simulator announced

Gazebo Sim is an open source robotics simulator with multiple physics engines and a graphical interface. It can simulate cameras, laser range finders, contact sensors, IMUs and GPS, optionally adding noise. Custom plugins let users control robots, sensors and environments.

Key Points:

- Multiple physics engines are supported.

- Optional noise can be added to sensor data.

🔗 Resources:

- [Original post](https://x.com/dextune/status/2120798754370633846)
