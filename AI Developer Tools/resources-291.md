Superfluid is open‑sourced today. It is a local‑AI native LLM server for multi‑agent workloads on constrained resources such as laptops or workstations. It runs as a single serving daemon for a local LLM.

Key Points:

### 🤖 postgresai 0.17 release

postgresai 0.17 is released. It adds an outbound-only agent that never connects to your instance, a new pgai promql, and autovacuum checks that use each table's real trigger point. It also provides pg_stat_statements from all databases and VictoriaMetrics admin keys.

Key Points:

- **Outbound-only agent**: the platform never connects to your instance

### 📊 Arize AX launches Cost Agent for LLM spend analysis

Cost Agent is a managed agent in Arize AX that analyzes traces to identify sources of LLM and agent spend, quantifies impact, and suggests fixes. An analysis reported 35–40% estimated monthly savings. The feature is now available to Arize AX Enterprise accounts.

Key Points:

- **Savings estimate**: one analysis found 35–40% estimated monthly savings.

- **Availability**: Cost Agent is now available to Arize AX Enterprise accounts.

- **Run modes**: supports an automation run on a weekly schedule and a one‑time session run that returns a transcript with spend breakdown and fixes.
