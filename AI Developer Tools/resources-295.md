### 🤖 Ling-3.1-flash open source, 560B params, 1M context

Ling-3.1-flash is now open source with 560 B total parameters, about 25 B active per token and a 1 M-token context window. It can turn rough briefs into pages, mobile UIs, and interactive prototypes. Model weights and documentation are hosted on Hugging Face and ModelScope.

Key Points:

- **Open source release**: weights and docs on Hugging Face and ModelScope

- **Specs**: 560 B total parameters, ~25 B active per token, 1 M context length

### 🤖 AutoEnvScaling introduces self-building Harbor tasks

AutoEnvScaling turns Data Flywheel into a terminal task where a proposer agent builds complete Harbor tasks and sandbox. This enables self-play RL for terminal agents, allowing one model to improve as both builder and solver without human-in-the-loop.

Key Points:

- Proposer agent builds complete Harbor tasks and sandbox.

- Enables self-play RL for terminal agents, one model improves as both builder and solver, without human-in-the-loop.
