### 🤖 Intercom Gator launches free CoinGecko-style aggregator

Intercom Gator is a free CoinGecko-style market data aggregator for AI agents, installed via a single prompt. It gathers public market data from exchanges, blockchains and DEX pools, shares it via Trac’s peer-to-peer network, and builds local price views.

Key Points:

- **Install with one prompt**: download latest GitHub release, verify checksum, install locked dependencies, start daemon, show Bitcoin price, open dashboard, schedule hourly routine.

- Swarm of 100–200 agents claimed to easily outperform CoinGecko in market coverage and accuracy.
