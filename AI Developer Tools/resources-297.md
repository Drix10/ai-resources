### 🤖 Verifiable AI Agent reputation privacy trade-off details

Verifiable AI Agent reputation can come with a privacy trade-off. In the draft ERC-8004 spec, feedback value and tags are stored on-chain and the endpoint, file URI, and hash are emitted in events. The off-chain feedback file is optional.

Key Points:

- Feedback value and tags stored on-chain in ERC-8004 draft

- Endpoint, file URI, and hash emitted in events

- Off-chain feedback file optional

- Verifiable does not mean private
