### 🚀 Node.js 26 LTS now generally available on Vercel

Node.js 26 LTS is now generally available on Vercel with default use for new projects. It includes HTTP/2 for built-in fetch, the Temporal API, and V8 14.6 engine.

Key Points:

- **Default**: Node.js 26 is the default runtime for all new Vercel projects.

- **HTTP/2**: Built-in fetch uses HTTP/2 by default, allowing multiple requests to share a connection.

### 🤖 Pixeltable Chess Broadcast Scenes finds missing board frames by color

Pixeltable Chess Broadcast Scenes (app #40) detects that one-third of frames in chess broadcasts show no board and locates those frames using color analysis. The example includes a full media pipeline that samples frames at 5 fps, classifies shot type, and extracts board positions.

Key Points:

- 1 in 3 frames in four chess broadcast recordings contain no board.

- The app identifies missing-board frames by analyzing frame colors.
