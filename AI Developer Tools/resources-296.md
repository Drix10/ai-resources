### 🤖 Nemotron 3.5 Super VL E2EE inference 500+ tokens/sec on one GPU

NVIDIA Nemotron 3.5 Super VL is an open multimodal model that runs with end-to-end encrypted inference at over 500 output tokens per second on a single NVIDIA B300 GPU. It reads documents, screenshots, images and video, reasons over them and calls tools through an OpenAI-compatible API. The model uses a 120B-parameter mixture-of-experts architecture with only 12B active per token.

Key Points:

- 500+ output tokens per second for a single request on one B300 GPU.

- 120B total parameters, 12B active MoE per token, with built-in Multi-Token Prediction.
