### 🤖 Task Launcher – side panel adds custom prompts per project

Task Launcher adds a side panel in Orca that lets you set a custom prompt for each project and launch a task with a button click. It runs GitHub issues as branches and worktrees from the panel. Installation is through Orca Settings → Plugins using the community catalog.

Key Points:

- Custom prompt per project set in the side panel

- Clickable button triggers a task run

- Runs GitHub issues in separate branches and worktrees

- Install via Settings → Plugins → Add marketplace URL then search for Task Launcher
