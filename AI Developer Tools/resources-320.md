### 🤖 LFM3 1.7B fine-tuned for Nushell calls scores 92.6%

LFM3 1.7B fine-tuned for Nushell calls scores 92.6% on 231 held-out requests in a wasm nu sandbox. gpt-6-luna got 22.1% and claude-haiku-5-5 got 13.0% on the same test.

Key Points:

- LFM3 + LoRA 92.6% on 231 held-out requests

- gpt-6-luna 22.1% on same test
