### 🤖 WhoDB – connected data platform announced, open source

WhoDB is a connected data platform that links databases, warehouses and files and maps their relationships. It is open source and built by Clidey. A retail team reduced inventory planning time from 3-4 hours to 10-15 minutes using WhoDB.

Key Points:

- Connected data platform that links databases, warehouses and files, then shows how they relate

- Reduced inventory planning from 3-4 hours to 10-15 minutes in a retail use case
