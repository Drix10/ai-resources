### 🚨 PAN-OS CVE-2026-0322 exploited management interface RCE – hotfixes released

PAN-OS CVE-2026-0322 allows an attacker with a valid admin password and network access to the management page to execute code as root. CISA added the vulnerability to its KEV list and gave agencies three days to remediate. PAN-OS hotfixes are available and the admin page should be limited to internal IPs immediately.

Key Points:

- CVE-2026-0322 exploited management interface RCE.

- CISA gave agencies three days to address the issue.

- PAN-OS hotfixes are out.

- Lock the admin page to inside IPs tonight.
