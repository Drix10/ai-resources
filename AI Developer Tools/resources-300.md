### 🤖 Raycast Enterprise MDM deployment with signed PKG

Raycast Enterprise adds MDM deployment support, providing a signed and notarized installer package for each macOS release. IT can push the package through Jamf, Intune, Iru or any MDM that distributes .pkg files, and control update timing. Sign-in is limited to work email addresses and Raycast replaces Spotlight’s ⌘ Space shortcut from first launch.

Key Points:

- Signed PKG for every release, notarized by Apple.

- Deployable with Jamf, Intune, Iru or any MDM that installs .pkg files.
