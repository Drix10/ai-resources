### 🚀 Claude API max request size increased to 128MB

Claude API raised max request size for Messages and Token Counting from 32MB to 128MB. Image-heavy requests like long computer-use sessions and big PDFs now have ~4× more room.

Key Points:

- Max request size raised from 32MB to 128MB.

- Image-heavy requests like long computer-use sessions and big PDFs were previously hitting 32MB with plenty of context window left; now you get ~4× more room.

### 🤖 LFM3-Omni-2B runs locally in browser at 280 tok/s

LFM3-Omni-2B runs 100% locally in a browser, achieving ~280 tokens per second on an M4 Max. It uses custom WebGPU kernels and handles visual, audio, or text input, outputting interleaved text and audio tokens.

Key Points:

- **Performance**: ~280 tok/s on M4 Max, 90 ms to first token, 140 ms to first audio.

- **Capabilities**: first true omni model running end-to-end locally, accepts visual, audio, or text and produces interleaved text and audio tokens.
