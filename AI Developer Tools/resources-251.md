### 🕰️ Watcher - Real-time Event Monitoring

Type this into the chat while the agent is still working: "Tell me when this finishes and summarise what changed." That's a Watcher. It waits for the event, then reports back into the same chat. Point it at a pipeline run, or at PR checks on a worktree. Set it, then go do something else.

Key Points:
• A Watcher is a real-time event monitoring tool.
• It waits for an event, then reports back into the same chat.
• Point it at a pipeline run or PR checks on a worktree.
