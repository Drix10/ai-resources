### 🤖 Playwright browser security reminder – no bundled browsers, pinned test builds

Playwright does not bundle browsers; MCP or CLI use the stable Chrome/Edge on your machine with normal updates. The test runner downloads Chrome for Testing, pinned to a specific build, and runs with the sandbox off by default. The library API also launches the pinned build with sandbox off unless overridden.

Key Points:

- MCP or CLI use the stable Chrome/Edge on your machine, receiving normal updates, no config edit needed

- npx playwright install downloads Chrome for Testing, pinned to the build tested against, runs with sandbox off by default

🔗 Resources:

- [Original post](https://x.com/playwrightweb/status/2117638981454291252)
