### 🚀 Universal Scrape announced by Firecrawl

Universal Scrape is a new service that lets agents pull context from web pages, PDFs, images, profiles, financial data, podcasts and more. It provides access to data from the web, files, and over 200 providers through a single API.

Key Points:

- **Service**: Universal Scrape offers multi‑source data extraction for agents.

- **Integration**: Supports over 200 providers via the Alexandria platform with one API.
