### 📊 MoPort view-aware 2D interface achieves R@1 0.5674 on HumanML3D

MoPort is a view-aware 2D interface for motion language models that reaches R@1 0.5674 on HumanML3D. It uses Paired View Alignment and Camera-Modulated Encoding to map 2D poses to consistent latent representations.

Key Points:

- R@1 0.5674 on HumanML3D benchmark.

- R@1 0.3286 on KIT-ML benchmark.

- [Original post](https://x.com/CSVisionPapers/status/2118382433535918584)

### 🤖 Proof-Carrying Evolution: Black-Box Search, White-Box Flight benchmarks

Proof-Carrying Evolution: Black-Box Search, White-Box Flight reports that the strongest language models beat classical baselines on every run for linear control problems. The study compares four language models with classical search and synthesis on docking, pursuit, and attitude control tasks.

Key Points:

- Strongest models beat standard classical baselines on every run for linear problems.

- On SO(3) no model outperforms CMA-ES when mixed with classical mutation.
