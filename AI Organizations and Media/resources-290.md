### 📊 From Local Recovery to Unified Generation

From Local Recovery to Unified Generation: Discovering Triple Set in Knowledge Graphs via Observation-Anchored Latent Diffusion introduces LatentDiff, a unified latent generative framework for triple set prediction. It encodes the whole graph into relation-aware latent embeddings with a residual-quantized autoencoder and uses an observation-anchored latent diffusion model for denoising. Experiments on three benchmarks show it outperforms the state-of-the-art by 5.4 percentage points in Fₜₛₚ.

Key Points:
