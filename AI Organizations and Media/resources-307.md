### 🤖 Delegent cuts coding cost 67% with 27B FP8 model

Delegent uses Claude Code as frontier model and delegates routine subtasks to a small local model. A 27B FP8 submodel lowers frontier cost by 67% on long-horizon coding and 59% on agentic search, with no performance loss. A 2B model that runs on a laptop still cuts coding cost by 66%. Adding the 27B model costs 3–10 cents per coding task at API rates.

Key Points:

- 27B FP8 submodel lowers frontier cost 67% for long-horizon coding.

- 27B FP8 submodel lowers frontier cost 59% for agentic search.

- 2B submodel fitting on a laptop reduces coding cost 66%.

- 27B model adds 3–10 cents per coding task at API prices.

### 📊 ComputeWise measuring and fixing GPU waste, benchmark released

ComputeWise is a benchmark with a simulated GPU that replays recorded training runs, letting hundreds of AI research agent experiments run without real hardware. Agents using GPUs spent only 52% of time on work needed for the final answer, with 22% on unneeded runs and 26% idle. A harness that combines prompting and deterministic code removed over 80% of the extra time to the answer across five models.

Key Points:

- **GPU time use**: 52% needed, 22% unneeded, 26% idle.

- Harness reduced extra answer time by >80% across five models.

### 🤖 Generalist Action Critic raises HD-Score to 43.2 in autonomous driving

Generalist Action Critic (GAC) is a zero-shot framework that uses a frozen frontier model as an action critic to evaluate and reselection trajectories from specialized planners. On HUGSIM it lifts DrivoR’s HD-Score to 43.2, a state-of-the-art result without extra simulation data.

Key Points:

- GAC improves closed-loop driving safety across three planners with relative HD-Score gains up to 32.1%.

- On NAVSIM v1 GAC corrects up to 52.13% of unsafe trajectory selections while adding new failures in only 0.67% of high-quality selections.
