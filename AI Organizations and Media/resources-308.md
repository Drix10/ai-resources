### 🤖 Learning from Recurrence: Looped Models 46.2% math gain

Learning from Recurrence: Internalizing Depth-Induced Preferences in Looped Language Models shows a 46.2% mean relative gain on six math benchmarks. The paper retrofits OLMo-2-1B with a shared recurrent block and trains it via preference write-back. Using the updated block only on passes two-through-four recovers nearly the entire four-pass gain on GSM8K.

Key Points:

- Preference write-back trains the shared block to produce four-pass continuations in a single pass.

- Updated block applied only on passes two-through-four recovers nearly the whole four-pass gain on GSM8K.

- Retrofits pretrained OLMo-2-1B with a shared recurrent block and evaluates four-pass depth.

### 🤖 Do We Still Need Reinforcement Learning When We Can Read the World Model

Do We Still Need Reinforcement Learning When We Can Read the World Model shows a coding agent that reads environment source code, writes a control policy as a program, and refines it with online feedback or offline data, without task-specific RL training. Key Points:

- Agent reads environment source code and generates a programmatic policy.

Key Points:

### 🤖 On the Effectiveness of Resampling for Supervised GAD – results

On the Effectiveness of Resampling for Supervised Graph Anomaly Detection reports benchmark findings on 17 datasets. It evaluates class weighting and up to six oversampling methods across ten detector configurations from three families. Gaussian-noise oversampling (ROSE) gains up to 5.2 AUPRC points in four tree and tabular model configurations on injected anomalies. Tuning tree detectors adds about three points, matching ROSE’s gain and reducing ROSE’s benefit by half or more.

Key Points:

- Compared class weighting and up to six oversampling strategies in ten detector configurations on 17 datasets.

- Gaussian-noise oversampling (ROSE) achieved up to 5.2 AUPRC point improvement in four tree and tabular foundation model configurations.
