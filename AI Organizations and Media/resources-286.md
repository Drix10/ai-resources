### 🤖 Lumina simulation models early universe up to 2 billion years

Lumina is a large-volume, high-resolution computer simulation that follows the first 2 billion years after the Big Bang. It spans 500 megaparsecs (≈1.6 billion light-years) and tracks dark matter, gas, stars and radiation. The run used the Frontier supercomputer with over 100,000 CPU cores.

Key Points:

- **Volume**: 500 megaparsecs (≈1.6 billion light-years) across the simulated patch.

- **Resolution**: half a trillion elements, about 30 × higher than IllustrisTNG, in a volume 100 × larger than previous simulations.

### 🤖 PaperFormalizer author-in-the-loop autoformalization tool launched

PaperFormalizer is a Lean-based pipeline that converts LaTeX papers into a dependency graph, audits statements, and formalizes proofs in Lean. It interacts with the author to resolve ambiguous statements and outputs an annotated paper, change report, and linked Lean code. The system runs inside a coding agent (Claude Code or Codex) and is publicly available.

Key Points:

- Runs inside a coding agent (Claude Code or Codex).

- Produces an annotated revised paper, a change report, and Lean code linking each declaration to its statement.

🔗 Resources:

- [Original post](https://x.com/SciFi/status/2114753782537994298)
- [PaperFormalizer: Author-in-the-Loop Autoformalization of Research Papers in Lean](https://arxiv.org/abs/2610.31810) - Linked page
