### 🤖 OpenJaws Open Hardware UMI Framework with Stereo Localization released

OpenJaws is an open hardware and software framework for sensorized Universal Manipulation Interface that uses a modular 3D-printed gripper and low-cost stereo camera to obtain metric camera trajectories. It introduces the UMI-Loc-Bench-v1 benchmark and shows stereo localization outperforms monocular alternatives. Code, data and videos are released under a commercially permissive license.

Key Points:

- OpenJaws pairs a modular 3D-printed gripper with a low-cost stereo camera for metric camera trajectories.

- UMI-Loc-Bench-v1 benchmark quantifies real-world localization accuracy for handheld data-collection devices.

### 🤖 Nonlinear Direct Feedback Alignment for Scalable Backpropagation-Free Training announced

Nonlinear Direct Feedback Alignment (NDFA) introduces a lightweight nonlinear surrogate subnetwork for each hidden layer’s feedback. The paper reports that NDFA consistently outperforms existing DFA methods and narrows the performance gap to backpropagation across CIFAR-10, CIFAR-100, SVHN, and ImageNet. Code is released alongside the arXiv submission.

Key Points:

- Introduces NDFA, using a surrogate subnetwork to construct nonlinear feedback for each hidden layer.

- Experiments on residual networks and vision transformers show NDFA beats prior DFA approaches on multiple vision datasets.
