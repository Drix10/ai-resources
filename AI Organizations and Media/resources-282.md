### 📊 Co-Adaptive Entropy Modeling reduces distortion 15-24% in perceptual audio coding

Co-Adaptive Entropy Modeling and Rate-Distortion-Optimal Bit Allocation for Perceptual Audio Coding presents a coder where entropy model and bit allocation co-adapt across blocks without side information. It lowers band noise-to-mask ratio by 15-24% versus a solver without entropy-coding awareness and an additional 3-4% from co-adaptation. A MUSHRA test at 80 kbps per channel confirms the ranking.

Key Points:

- **Reduction**: entropy-coding-aware bit allocation lowers distortion by 15-24% relative to the same solver without it.

- **Additional gain**: co-adaptation removes a further 3-4% (up to 15% on oboe) that a backward-adaptive coder alone cannot achieve.

### 🚀 Content-Edited Layout Generation for Graphic Design announced

Content-Edited Layout Generation for Graphic Design introduces the CELG task and releases the InstructEdit dataset. The paper defines CELG as generating an adapted background and layout conditioned on text and optional foreground. It also presents a two-flow multimodal flow matching model that combines a pretrained image editor with a layout flow transformer.

Key Points:

- **Task**: Content-edited layout generation (CELG) extends conventional content-aware layout generation.

- **Dataset**: InstructEdit contains aligned source images, target canvases, instructions, and layouts created by the Search-Compare-Edit (SCE) framework.
