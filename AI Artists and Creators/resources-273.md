### 🤖 dsh-superagent agent framework for GitHub issues and PRs

dsh-superagent is an agent framework that works through a repo's GitHub issues and PRs with many agents in parallel. It is designed to take as little human attention as possible while delivering as much value as possible.

Key Points:

- **Framework**: works through a repo's GitHub issues and PRs

- **Design goal**: minimal human attention, maximal value
