### 🤖 Letterpress-1 beta released for growth engineering

Letterpress-1 beta released as a coding agent, harness, and IDE built for growth engineering. The IDE is embedded in sites; press ⌘+L, authenticate, edit text, and a pull request is opened automatically.

Key Points:

- **Beta release**: Letterpress-1 is the world’s first coding agent, harness, and IDE purpose-built for growth engineering.

- **IDE integration**: Press ⌘+L, authenticate, edit text directly on your website, and Letterpress-1 automatically opens a pull request.
