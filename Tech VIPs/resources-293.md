### 🤖 Gateway and Workers integration public beta

Gateway and Workers integration is now in public beta. Use the Forward action to run custom code on traffic and access user context without managing a separate proxy.

Key Points:

- **Integration status**: public beta.

- **Forward action**: runs custom code on traffic and accesses user context without a separate proxy.

### 🤖 Claude Managed Agents dynamic workflows go public beta

Claude Managed Agents dynamic workflows are now available in public beta, a new multi-agent orchestration type. A lead agent writes a plan that runs across many agents in phases, combining the results at the end.

Key Points:

- Claude Managed Agents dynamic workflows are now in public beta.

- Lead agent writes a plan that runs across many agents in phases, combining results at the end.

- First full-length workshop on Claude flows kicked off by cjav_dev and Harrison Stall at AI Engineer NYC.
