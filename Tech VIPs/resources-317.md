### 🚨 1Password hacked via employee GitHub breach, copy of records

1Password was hacked after an employee’s GitHub account was compromised, allowing malicious code to be pushed into the backend to copy customer records. Users are advised to change all passwords.

Key Points:

- Hack entry through one employee’s GitHub account.

- Malicious code added to 1Password backend to copy customer names, emails, and account IDs.

### 🤖 Rex adds program resume via OSC 7577 terminal protocol

Rex can resume programs through a server restart using new terminal protocol OSC 7577. It works with plain terminal escape sequences and does not need special integration. Rex ships with built-in support for Claude Code and emits OSC 7577 in a session start hook. A Lua-based configuration lets users opt-in per program or disable globally.

Key Points:

- OSC 7577 escape sequence enables program restart after server restart.

- Lua-based config allows filtering by program name, path, working directory, flags, or global disable.
