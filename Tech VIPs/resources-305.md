### 🚨 ToolShell vulnerabilities exploited in fileless SharePoint breach

ToolShell vulnerabilities CVE-2025-53770 and CVE-2025-53771 were exploited in a fileless SharePoint breach on Christmas Eve 2025. Attackers hid a web-shell in IIS process memory, escalated privileges, and attempted to deploy Warlock ransomware, which Kaspersky Endpoint Security blocked.

Key Points:

- CVE-2025-53770 and CVE-2025-53771 exploited.

- Web-shell hidden in memory of an IIS process.

- Warlock ransomware deployment blocked by Kaspersky Endpoint Security proactive protection module.
