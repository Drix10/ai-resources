### 🤖 Goose programming language announced

Goose is a new programming language. It claims to be safer, faster and use less memory than Rust or C++ for algorithms with tightly packed, flat data structures. It also claims to represent more kinds of data structures as flat, pointer‑free bytes than any language the author knows.

Key Points:

- **Claim**: Safer, faster and less memory than Rust/C++ for certain algorithms.

- **Claim**: Can represent more kinds of data structures as flat, pointer‑free bytes than any known language.
