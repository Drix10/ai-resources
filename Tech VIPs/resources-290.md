### 🤖 Gliff remote desktop announced for RS 4.5

Gliff is a remote desktop client that connects to Omarchy boxes over SSH. It shows each remote machine in a tabbed window and uses GPU acceleration for video. The tool will be included in RS 4.5.

Key Points:

- **Feature**: single app with tabs per server that streams over SSH using GPU acceleration

- **Requirement**: Hyprland must run on both local and remote machines and SSH access is needed

### 🤖 ARK cost per mile estimate and autonomous taxi reduction

ARK reports the cost per mile of a personally owned vehicle has stayed around $1.10 for 90 years, adjusted for inflation. By 2035 autonomous taxis could cut that cost by 77%. The claim suggests a large efficiency gain for future transport.

Key Points:

- **Cost per mile**: ~$1.10 for 90 years (inflation‑adjusted)

- **Autonomous taxis**: 77% cost reduction by 2035
