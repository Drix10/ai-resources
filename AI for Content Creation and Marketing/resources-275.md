### 🚀 Ahrefs API adds folder management and 1M domain list

Ahrefs API adds programmatic folder management for projects and a new endpoint to pull the top 1M domains by DR. It also introduces a PATCH endpoint for Brand Radar prompt country and tag updates and automated content audits that score URL coverage against core topics.

Key Points:

- **Folder management**: list, create, move, or remove project folders via API.

- **Top 1M domains**: retrieve domains ranked by DR with range support in a single call.

- **Brand Radar**: PATCH endpoint to add or remove countries and tags on prompts.

- **Content audits**: analyze pages ranking for a keyword, identify core topics, and score a target URL’s coverage.
