### 🚨 PressBot admin username leak fixed in a day

PressBot revealed that its real WordPress admin username was exposed via the users sitemap and other public endpoints, and the issue was resolved within a day. The fix was released in PressBot version 1.20 and includes hiding usernames, disabling XML-RPC, and a built-in username rename tool.

Key Points:

- Version 1.20 adds Site Check, Hide usernames, XML-RPC disable, and username rename features.

- The users sitemap at /wp-sitemap-users-1.xml lists author slugs that match admin login names.

🔗 Resources:

- [Original post](https://x.com/heygreendev/status/2111182775231369594)
- [Your WordPress Admin Username Is Probably Public. Ours Was.](https://pressbot.io/your-wordpress-admin-username-is-probably-public-ours-was/) - Linked page
