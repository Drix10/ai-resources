### 🤖 Roblox AI tools usage spikes in top games, 80%

Roblox reports over 80% of its top 100 games used AI tools to speed creation, and daily asset uploads to its cloud tripled month-over-month. Time spent using AI tools tripled for top creators, and daily MCP server users grew nearly fivefold.

Key Points:

- 80% of the top 100 games on Roblox used AI tools in the past month.

- Daily asset uploads to the Roblox cloud tripled month-over-month.

### 🤖 Orshot integrates with Buffer

Orshot now integrates with Buffer, sending every generated image, carousel or video to a Buffer queue. Integration works from the editor, the API or a Google Sheet. Built for #BufferCommit.

Key Points:

- **Integration**: connect Buffer once and every image, carousel or video generated from a template lands in your Buffer queue.

- **Access**: integration available from the editor, the API or a Google Sheet.
