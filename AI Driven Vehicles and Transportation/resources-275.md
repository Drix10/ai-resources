### 📊 Claude Code replicates webcam location via doppler audio

Claude Code was used to predict the location of a live webcam 7 km south of Southampton, UK, using doppler effect in audio spectrogram and open-source aircraft data. The resulting heatmap peaks at the webcam’s actual position.

Key Points:

- Replicated using Claude Code, a live webcam 7 km south of Southampton, UK.

- Predicted location derived from doppler effect in audio spectrogram combined with open-source aircraft location data.
