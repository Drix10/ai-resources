### 🤖 EgoHumanoid-V2 announced for human-to-humanoid whole-body skill transfer

EgoHumanoid-V2 is a framework that transfers coordinated whole-body loco‑manipulation skills from egocentric human data to humanoid robots. It uses a coarse‑to‑fine action alignment that combines kinematic reference correction with dynamics‑aware refinement. The system demonstrates zero‑shot skill transfer on four real‑world tasks and reports results using 200 human demonstrations.

Key Points:

- **Highlight**: First egocentric human‑to‑humanoid skill transfer framework for coordinated whole‑body loco‑manipulation.

- **Highlight**: Coarse‑to‑fine action alignment combines kinematic reference correction with dynamics‑aware refinement.
