### 🤖 AD-Memo language-based memory driving agent announced

AD-Memo is a Vision-Language-Action autonomous driving agent that adds language-based memory to record surrounding objects critical to driving. The memory is appended to the agent’s input and used in later reasoning and decisions. Training uses supervised fine-tuning followed by Da Capo, a semi-closed-loop reinforcement learning algorithm that assigns trajectory-level advantage to memory and step-level advantage to driving.

Key Points:

- Language-based memory extends the agent’s Chain-of-Thought to record decision-relevant objects.

- Da Capo uses trajectory-level advantage for memory and step-level advantage for driving.

- [Original post](https://x.com/drmapavone/status/2118722438553092163)
