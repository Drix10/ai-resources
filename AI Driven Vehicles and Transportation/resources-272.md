### 🤖 L3G-World KAIST world model memory 3D Gaussians 9 fps

L3G-World (KAIST) is a world model that stores 3D Gaussians of VAE latents and renders directly into a video model’s latent space. Memory grows with the scene rather than clip length and runs in real-time at 9 fps. Code will be released.

Key Points:

- Memory is 3D Gaussians holding VAE latents.

- Real-time performance at 9 fps.

### 🤖 World Labs Gaussian splats from Marble worlds, 20 min

World Labs now turns the worlds you generate in Marble into Gaussian splats you can download as SPZ or PLY files. Conversion takes about 20 minutes in Marble Studio. Developers can use the API to build splats from photos inside their apps.

Key Points:

- Gaussian splats downloadable as SPZ or PLY files

- Conversion takes about 20 minutes in Marble Studio

- API lets developers build splats from photos inside apps

### 🤖 comma_ai four Autopilot visualization accuracy

comma_ai four Autopilot visualization shows direction accuracy decreases as frame rate increases. Measured match rates drop with higher FPS.

Key Points:

- **5 FPS**: 80% of moving cars matched their actual driving.

- **20 FPS**: 63% of moving cars matched their actual driving.
