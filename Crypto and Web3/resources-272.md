### 🚨 1Password breach – hackers accessed GitHub, stole data

1Password breach – hackers accessed GitHub, stole data, including customer names, emails, IDs, timestamps, keys and tokens. Vaults, passwords, Secret Keys and recovery keys remain safe, with no account takeovers found.

Key Points:

- **Breach**: hackers hijacked an employee's GitHub account and pushed malicious code into backend.

- **Data stolen**: customer names, emails, account IDs, login timestamps, public keys, authentication parameters, account invitation and recovery tokens; also access to build and deployment systems.

### 🤖 P≠NP Contributor rewards – 100M PNP set aside for proof contributors

P≠NP · Contributor rewards launches a token pool of 100 million PNP for anyone whose GitHub work contributes to a proof of P = NP or P ≠ NP. The pool is 10% of a fixed 1 billion PNP supply and will be distributed after a proof is verified by Alex Masmej. Points are awarded for merged pull requests, unique lemmas, and work used in the final proof, with payouts proportional to points earned.

Key Points:

- 100 million PNP allocated to contributors, representing 10% of a 1 billion token supply.

- An eligible merged pull request earns 1 point; a merged proof of a unique project gap adds 2 points; work used in the final proof adds another 2 points; a checked lemma on the proof path totals 5 points.
