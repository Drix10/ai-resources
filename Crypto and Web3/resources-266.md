### 🚀 Aethir decentralized GPU cloud eliminates egress fees for checkpoint transfers

Aethir’s decentralized GPU cloud runs on a zero-egress model, removing the cost of moving state between steps. At typical hyperscaler egress rates of 8-12 ¢/GB, a 100GB checkpoint can cost more than an hour of GPU compute. Persistent memory is presented as cheap by design rather than a billed penalty.

Key Points:

- Hyperscaler egress fees are 8 to 12 cents per GB.

- A 100GB checkpoint transfer can cost more than an hour of GPU compute.

- Aethir’s cloud uses a zero-egress model, making state moves a rounding error.

- Persistent memory is positioned as cheap by design, not a gigabyte-based penalty.
