THORChain's admin key is not an admin key in the classical sense, but rather a provisional or interim key. It doesn't have any authority over the protocol and can only make configuration changes that nodes can override. This clarification provides a deeper understanding of the admin key's role in THORChain.

Key Points:

- **Admin Key Clarification**: The admin key is not an admin key in the classical sense, but rather a provisional or interim key.

- **No Authority Over Protocol**: The admin key doesn't have any authority over the protocol and can only make configuration changes.

- **Node Override**: Nodes can override the configuration changes made by the admin key.
