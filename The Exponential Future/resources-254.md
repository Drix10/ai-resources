### 📊 Mission Control dashboard flags bots daily, alerts token use

Mission Control is a bot fleet operations dashboard that audits bots each morning and flags them red, yellow, or green. It forecasts plan exhaustion, tells which bots to pause, merge, or tighten, and provides a live dashboard plus a daily PDF report.

Key Points:

- Audits every bot each morning and flags each one red, yellow, or green.

- Forecasts whether you'll run out of plan before reset and tells exactly what to pause, merge, or tighten to save tokens.

- On its first run, caught weekly usage on track to run out three days early and pointed to the bots causing it.
