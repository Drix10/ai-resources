### 🤖 Fern model – 10M token context, 0.5M lines code

Fern, Mirendil’s first model, is pretrained from scratch with up to 10M tokens of context. It corresponds to roughly 0.5M lines of code or days of an agent’s work, all in context at once. The initial release, Fern 0.1, underwent a short round of post-training.

Key Points:

- **Context length**: up to 10M tokens

- **Scale**: ~0.5M lines of code (roughly Megatron-LM scale)

- Fern 0.1 had a short round of post-training
