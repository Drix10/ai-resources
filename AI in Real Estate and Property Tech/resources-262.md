### 🤖 Iris-3B Metal launches Mac app with 9.81 s 1024×1024 Turbo

Iris-3B Metal is a native macOS app that runs Speridlabs' 3B pixel-space diffusion model locally on Apple Silicon. Turbo mode (4 steps, 1024 × 1024) generates images in 9.81 seconds on an M5 MacBook Pro with 24 GiB. The release includes a SwiftUI app, CLI, Python API and local HTTP API and requires macOS 15 and Python 3.11.

Key Points:

- Turbo weights are 6.0GB; the Qwen text encoder is 8.9GB.

- Supports depth maps and 4× image restoration/upscaling in addition to text-to-image.

### 🤖 Pro Wave open-source DAW launches with 62/176 menu entries functional

Pro Wave is an open-source music app written in pure Rust that mimics Logic Pro’s layout. It ships with tracks, MIDI and audio regions, a Piano Roll with quantize and swing, a Mixer with sends and automation, and a built-in 48-voice synth. The early build reports 62 of 176 menu entries working. It runs on Windows, macOS and Linux and supports WAV, FLAC, MP3, Ogg, M4A and ALAC files and any time signature, including 7/8.

Key Points:

- 62 of 176 menu entries work so far

- Built-in subtractive synthesizer with 48 voices

### 🤖 UniRig – automatic skeleton and skinning announced

UniRig predicts a skeleton and skinning weights for any 3D mesh, ready to animate, built by Tsinghua University and Tripo. It runs skeleton prediction then skinning, and the authors point to SkinTokens, a successor that combines both steps in one pass.

Key Points:

- **Skeleton & Skinning Prediction**: UniRig predicts a skeleton and skinning weights for a 3D mesh.

- **Successor**: SkinTokens does both skeleton prediction and skinning in a single pass.

### 🤖 3D Model Anything – iPhone LiDAR scan to editable Three.js scene

3D Model Anything lets you scan a room with a LiDAR iPhone and rebuild it as an editable Three.js scene using a coding agent. The repo includes an iPhone app, a Three.js viewer, and the scan-to-threejs skill. It requires Node.js 22.12+ for the viewer and a LiDAR-equipped iPhone or iPad for scanning.

Key Points:

- Repo contains iPhone LiDAR capture app, Three.js viewer, and scan-to-threejs agent skill.

- Viewer runs with Node.js 22.12 or newer; scanning needs a LiDAR iPhone or iPad.

### 🤖 RGB MoCap launches Windows app for video-to-animation conversion

RGB MoCap is a native Windows application that turns any video into editable human animation on a local PC. It reconstructs one or several people, shows body mesh and bones, and fixes foot and palm sliding with contact timings you can edit. The tool can retarget motion to Mixamo FBX, VRM or PMX characters and export FBX, BVH, VMD or a Blender project.

Key Points:

- Reconstructs one or several people from a clip, shows body mesh and bones, and fixes foot and palm sliding with editable contact timings.

- Retargets motion to Mixamo FBX, VRM or PMX characters and exports FBX, BVH, VMD or a portable Blender project.
