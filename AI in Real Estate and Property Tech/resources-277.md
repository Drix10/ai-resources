### 🤖 PixelFX for Godot adds unofficial port with CPU pixel generation

PixelFX for Godot is an unofficial port of patch-gg/pixelfx for Godot 4.3+. It generates pixels on the CPU in GDScript and uploads textures to Godot. The addon includes five released effects, preset saving, inspector controls, and playback features such as pause, restart, speed, looping and fade.

Key Points:

- Generates pixels on the CPU in GDScript and uploads textures to Godot.

- Playback supports pause, restart, speed, looping and fade.

### 🤖 sprite-turntable releases 360° 72-frame turntable tool

sprite-turntable provides a full character turntable from one front view, generating a 360° sequence of 72 transparent PNG frames. An offline browser viewer lets you drag to rotate and zoom, showing the nearest frame without blending, keeping hair and edges sharp. The view stays at a fixed height; views from above or below are not included.

Key Points:

- 360° sequence of 72 transparent PNG frames generated from a single front view.

- Offline browser viewer supports drag rotation, mouse-wheel zoom, and displays nearest frame without blending.

### 🤖 spritefx – Python tool generates palette-locked VFX sprite sheets from JSON

spritefx is a Python tool and Claude Code skill that creates pixel-art VFX sprite sheets from JSON specifications. Every output pixel uses a palette colour with no soft alpha, and 22 automated craft checks validate flash order, flicker, stray pixels, loop seams and readability. The tool outputs a PNG strip of uniform cells and a JSON file with timings, tags, events and an anchor.

Key Points:

- 22 automated checks cover flash order, flicker, stray pixels, loop seams and readability, and block output if any fail.

- Output includes a PNG strip with uniform cells and a JSON file containing timings, tags, events and an anchor.

### 🤖 Lit – uncapped 2D lights and soft shadows for Godot 4

Lit adds point, directional and spot lights with soft or hard shadows and live editor updates for Godot 4.5+. A single node provides over 20 post-processing effects and reads normal maps and specular directly from CanvasTexture.

Key Points:

- **Uncapped lights**: no 15-light limit, use as many lights as needed.

- **Three shadow algorithms per light**: Cone Traced, Raymarched, and Stochastic, selectable via dropdown.

### 🤖 Papermorph turns books into narrated lessons and animated stories

Papermorph is an AI agent skill that converts textbooks into interactive lessons and picture books into paper-puppet films. Lessons animate formulas and diagrams step by step with narration, and math practice grades the mathematics rather than matching exact text. The skill outputs static pages or folders that can be hosted anywhere without a server or account.

Key Points:

- Lessons animate formulas and diagrams step by step with narration.
