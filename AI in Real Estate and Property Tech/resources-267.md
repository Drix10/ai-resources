### 🤖 Bonsai voxel engine announces full-world visibility and 1 billion-block world size

Bonsai is a procedural voxel engine written in C that keeps the entire world visible at all times, supporting a maximum world size of roughly 1 billion blocks per dimension. Terrain generation runs on the GPU via GLSL shaders and the engine includes hot shader and game-code reloading, deferred shading, HDR lighting, and SDF world editing.

Key Points:

- **Maximum world size**: ~1 billion blocks, cubed, view distance the entire world.

- **Terrain generation**: fully procedural on the GPU using regular GLSL shaders, user configurable.

### 🤖 PSD2Live adds import, rigging, animation and export features

PSD2Live lets you turn a layered PSD into a moving character with idle motion, blinking, nodding and hair physics. The open source editor includes skeletons, IK, cloth and hair simulation and can export to Cubism, VTube Studio, the web, game engines or video.

Key Points:

- **Feature**: Import a PSD and pick a preset for idle motion, blinking, nodding and hair physics.

- **Capability**: A local MCP server lets agents such as Claude Code and Codex edit projects.

### 🤖 RPG-JS – build browser RPG, run as MMORPG with same code

RPG-JS is a TypeScript framework for browser RPGs that lets you choose single-player or MMORPG operation at runtime. It includes maps, events, dialogs, inventory, skills, combat, saving and loading, and multiplayer synchronization.

Key Points:

- Runtime choice between single-player and MMORPG without rewriting the game

- Features include maps, events, dialogs, inventory, skills, combat, save/load, and multiplayer sync

### 🤖 NeoForge – free open source Minecraft modding API

NeoForge is a free, open-source, community-oriented API for Minecraft: Java Edition. It provides a Forge-based framework for creating and using mods. Users run an installer that attempts to add NeoForge to the vanilla launcher and then create a new profile to play. Documentation includes a Getting Started guide for mod creators.

Key Points:

- Free, open source, community oriented modding API for Minecraft: Java Edition

- Installer attempts to install NeoForge into the vanilla launcher environment and creates a new profile​

### 🚀 termscp terminal file explorer adds multi-protocol support

termscp is a terminal file explorer for uploading and downloading files over SCP, SFTP, FTP, FTPS, SMB and WebDAV. It runs on Linux, macOS, FreeBSD, NetBSD and Windows and can sync file changes and save passwords in the OS key vault.

Key Points:

- Supports SCP, SFTP, FTP, FTPS, SMB and WebDAV protocols.

- Available on Linux, macOS, FreeBSD, NetBSD and Windows.
