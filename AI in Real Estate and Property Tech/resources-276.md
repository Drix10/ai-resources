### 🤖 Spine Animation AI – Claude skill creates rigged Spine animations

Spine Animation AI is a Claude agent skill that turns art assets into rigged Spine animations and provides an interactive HTML preview. It positions body parts, builds the bone hierarchy and draw order, and generates idle, walk, run, attack, wave and jump animations.

Key Points:

- Auto-positions body parts from reference images, builds bone hierarchy and draw order, and generates idle, walk, run, attack, wave and jump animations.

- Delivers a skeleton file and an interactive preview that opens in a browser without a server.

### 🤖 SAM 3D Objects – single-image 3D reconstruction release

SAM 3D Objects reconstructs full 3D shape, texture, and layout from a single image and now provides code, model weights, an online demo, and Jupyter notebooks for single-object and multi-object reconstruction. The release includes example notebooks that combine object and human reconstructions in a shared frame of reference.

Key Points:

- Code, model weights, and an online demo are available.

- Jupyter notebooks cover single-object and multi-object reconstruction, with an example combining object and human reconstructions.

### 🤖 Pixel Plays – small isometric browser games

Pixel Plays offers small browser games presented as isometric pixel dioramas on pure white. Each game runs as a single HTML page with plain JavaScript, no build step, no dependencies, and no sprite assets. A shared shell and engine supply menu, rules, music, camera, shadows, and wind.

Key Points:

- Each game is an isometric pixel diorama drawn in real time without sprites or image assets.

- Games use plain JavaScript with no build step or dependencies and run on any static file server.

### 🤖 Godot Procedural Generation demos released with multiple algorithms

Godot Procedural Generation provides a set of demos that showcase procedural level chunks, dungeon generation, world maps with biomes and rivers, infinite worlds, and modular weapons. The repository includes RandomWalker, WorldMap, BasicDungeonGenerator, ModularWeapons, and several infinite world demos. Each demo can run step-by-step with a timer for visualization and debugging.

Key Points:

- RandomWalker uses a node that walks randomly on a grid, places hand-designed level chunks, and randomizes them.

- Infinite worlds include demos that generate asteroids with white noise and blue noise, and a layered generator for planets, moons, trade lanes, and asteroid belts.
