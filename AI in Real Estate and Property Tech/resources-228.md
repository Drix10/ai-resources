### 🤖 TypeScript Compilation - Native Executables

Vercel released Scriptc, a tool that compiles TypeScript directly to native executables. This process avoids bundling Node or V8 runtime dependencies. Static lowering is the default compilation mode for this utility.

Key Points:

• Scriptc compiles TS to native executables
• It does not require bundling Node or V8
• Static lowering is the default compilation method
• QuickJS integration is available via a `--dynamic` flag
