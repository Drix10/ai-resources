### 🤖 ThreeRT path tracing for three.js games launches with 60 fps real-time ray tracing

ThreeRT adds hardware ray-traced path tracing to three.js and runs scenes at 60 fps on Apple M3 Max. It traces shadows, bounce light, reflections and emissive surfaces without shadow maps or light probes. The same scene file runs as plain three.js in any browser. Benchmarks show 15.5 ms frame cost (60 fps) with a ΔE of 3.4, compared to three.js WebGPU at 34.7 ms (29 fps) and ΔE 10.1.

Key Points:

- 60 fps real-time path tracing on production scenes using hardware ray queries (Metal or Vulkan) with a software fallback.

- **Benchmark**: ThreeRT 15.5 ms per frame (ΔE 3.4) versus three.js WebGPU 34.7 ms (ΔE 10.1) on Bistro night 1280×720.

### 🤖 RhodoniteTS blends 38 VRM morph targets in browser

RhodoniteTS is a TypeScript Web3D library that can blend all 38 morph targets of a VRM character directly in the browser. It supports WebGL2 and WebGPU, loads glTF 1, glTF 2 and VRM assets, and includes an online drag-and-drop viewer with WebXR VR support.

Key Points:

- Blend all 38 morph targets of a VRM character in the browser.

- Supports WebGL2 and WebGPU rendering.

- Online viewer displays glTF, VRM and Effekseer package files via drag and drop.

- WebXR VR works in both WebGL and WebGPU modes.
