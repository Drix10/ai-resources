### 🤖 Diorama – 2.5D asset pipeline with TypeScript export to sprite sheets

Diorama lets developers write 2.5D game assets in TypeScript and export them as PNG/JPEG sprite sheets with atlas JSON. It uses a single shared camera and light, and guarantees deterministic pixel output. A local web viewer lets users browse exports, play animations, dress characters and paint scenes.

Key Points:

- **Export format**: rasterized PNG or JPEG sprite sheets with accompanying atlas JSON.

- **Asset types**: props, scenery, effects, rigged characters, item icons and HUD pieces share one camera and light.

- Animation data includes events, sockets and root motion; scenery assets can rest in states and play clips (e.g., doors, chests).

- Built for coding agents; includes skills, guides and a local web viewer for inspection and editing.

### 🤖 AIRI digital companion announced with browser, desktop and mobile support

AIRI is a digital companion that runs in modern browsers, desktop apps and on mobile devices. It supports VRM bodies, multiple voice synthesis back-ends and can play Factorio (proof of concept demo) and Kerbal Space Program.

Key Points:

- Voice synthesis options include ElevenLabs, Microsoft/Azure Speech and local Kokoro TTS.

- Audio input can come from Discord and xsai connects many LLM API providers.
