### 🤖 Strecs3D adds stress-based infill generation for 3D prints

Strecs3D lets users load a binary STL model and VTU analysis results, then automatically segments the model by stress thresholds and assigns dense or sparse infill via a slider. The processed model can be exported as a 3MF file for Cura or Bambu Studio slicing.

Key Points:
