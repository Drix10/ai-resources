### 🤖 Pokemon Auto Chess – open-source fan game with bot support and deployment guide

Pokemon Auto Chess is an open-source, non-profit fan-made game that lets you play against bots or host your own instance. It includes a local development server and precomputed data that must be updated after game data changes.

Key Points:

- Play Pokemon auto chess against bots or host your own instance.

- Local development server enables testing of configuration and code changes.

### 🤖 HaxeFlixel – free engine with native platform targeting and 80+ demos

HaxeFlixel is a free 2D game engine built on Haxe and OpenFL that targets multiple platforms natively. It offers a Getting Started guide, official API reference, and over 80 demo projects. Companion repositories provide addons, UI, tools, and templates.

Key Points:

- Free game engine with native platform targeting, built on Haxe and OpenFL

- More than 80 demo projects available for learning the engine

### 🤖 Arcade library – 2D Python game library announced

Arcade is a Python library for creating 2D games without learning a complex framework. It uses pyglet and OpenGL for rendering. Separate documentation exists for the stable version and a preview of the next release. A gallery displays games built with Arcade, including game jam entries.

Key Points:

- Uses pyglet and OpenGL for rendering

- Separate docs for the stable version and a preview of the next release
