### 🚀 fish-gen releases procedural pixel-art sea creatures with 7 kinds, 47 species

fish-gen is a tool that generates procedural pixel-art sea creatures with swim and turn animations; each seed creates a unique fish shape, fins, tail and colors. It offers 7 kinds and 47 species presets and can export GIFs, sprite sheets with JSON, PNG frames or a Godot 4 SpriteFrames resource.

Key Points:

- 7 kinds, 47 species presets, from neon tetras to whale sharks, mantas and octopus.

- Export options include GIFs, sprite sheets with JSON, PNG frames, and a Godot 4 SpriteFrames resource.

### 🤖 Image 2 Sculpt turns image into 3D sculpt with validation

Image 2 Sculpt converts a single image into a watertight 3D sculpt and measures the result against the reference image. The pipeline runs 38 fitting passes and reserves one view for validation. Blender can replay the entire build as a timelapse and export the model in .blend, GLB, OBJ and STL formats.

Key Points:

- 38 fitting passes recorded; one view held out for validation.

- Blender replays the build and exports .blend, GLB, OBJ and STL files.

### 🚀 Procedura – MCP integration released 2026-10-20

Procedura can turn text or a reference image into an editable 3D model and now runs inside Codex or Claude Code through MCP as of the 2026-10-20 release. It uses the current session’s model without needing a separate model API key and provides run previews, a final report, and optional physics checks if Isaac Sim is installed.

Key Points:

- **MCP release date**: 2026-10-20, enabling Procedura inside Codex or Claude Code.

- No separate model API key required; uses the model in the current session.
