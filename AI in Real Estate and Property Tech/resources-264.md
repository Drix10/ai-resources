### 🤖 Sprite Fusion Pixel Snapper adds CLI with default 16-color palette

Sprite Fusion Pixel Snapper is a tool that snaps AI-generated pixel art to a clean grid and quantizes colors. The CLI processes PNG or JPEG files or whole folders, uses 16 colors by default, and allows pixel-size overrides and custom hex palettes.

Key Points:

- Default palette uses 16 colors

- Supports batch processing of a directory

- Option --pixel-size overrides auto-detected pixel size

- Option --palette accepts comma-separated six-digit hex colors

### 🚀 blender-kiln – plugin creates real-size editable Blender models

blender-kiln is a Claude Code plugin that generates real-size 3D models from descriptions or photos and exports them as GLB, FBX, USDZ or STL with Draco and WebP compression. It handles sourcing, modelling, cleanup, CC0 scan texturing, optimization and validation.

Key Points:

- Generates editable Blender models at real size from an object description or photo.

- Exports models in GLB, FBX, USDZ or STL with Draco and WebP compression for the web.
