### 🤖 OpenSC2K – open-source SimCity 2000 remake with 4096-tile cities

OpenSC2K is an open-source SimCity 2000 remake built with Rust and Godot for macOS, Windows, and Linux. It supports cities up to 4096 tiles per side and external graphics, sound, and music packs, including an HD pack. The mod system provides a JavaScript runtime, game events, example mods, and a Chrome DevTools console, and the interface includes a Korean translation.

Key Points:

- Cities up to 4096 tiles per side.

- JavaScript runtime for mods with Chrome DevTools console.

### 🤖 MiniMax-H3 Prompt Rewriter 27B model launch with 32768-token context

MiniMax-H3 Prompt Rewriter is a 27B model fine-tuned from Qwen3.8-27B that rewrites prompts for MiniMax-H3 video and audio generation. It runs on vLLM with a 32768-token context, samples videos into 8 frames by default, and labels audio files without reading them. A dry-run flag saves the request for preview before execution.

Key Points:

- **Model size**: 27 billion parameters, fine-tuned from Qwen3.8-27B

- **Context window**: 32768 tokens; video frames default to 8; output limit 16384 tokens; image/frame limit 50 per request

### 🤖 GB Studio – drag-and-drop Game Boy editor with CLI exports

GB Studio lets you create Game Boy games with a drag-and-drop editor on Mac, Linux and Windows. Its command line tool can export a project as a Game Boy ROM, a Pocket file, a Web build, a GBDK project, or a ROM usage report. The music editor is also offered as a standalone web app.

Key Points:

- Drag and drop editor for Game Boy games on Mac, Linux, Windows.

- CLI can produce ROM, Pocket, Web builds, GBDK export, and usage report.

### 🤖 Zrythm – free DAW with audio/MIDI recording and plugin support

Zrythm is a free digital audio workstation that records audio and MIDI, includes takes, and offers a piano-roll editor with velocity editing and chord assistance. It supports VST3, CLAP, LV2, LADSPA and AudioUnit plugins, and recommends installing via prebuilt installers.

Key Points:

- Record audio and MIDI with takes

- Supports VST3, CLAP, LV2, LADSPA and AudioUnit plugins
