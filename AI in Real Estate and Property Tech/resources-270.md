### 🤖 Pixelbolt adds sword trails, auras, particle effects to PNG sprites in under 6 commands

Pixelbolt is an open-source tool that adds sword trails, auras and particle effects directly to existing PNG animation spritesheets. It can export animation files that work with Godot 4. The demo knight effects were generated with fewer than 6 commands and took less than a second on the creator’s computer.

Key Points:

- Open-source MIT-licensed tool called Pixelbolt.

- Generates effects in fewer than 6 commands and under a second.

### 🤖 Ursina – Python game engine with built-in 3D editor

Ursina is a Python engine for 2D and 3D games that includes a built-in 3D level editor. It provides procedural model classes such as Cylinder, Quad, and Terrain, and prefab classes like Draggable, Slider, and Sprite. The repository contains a Minecraft Clone example and uses Pillow for texture manipulation and Blender for .blend file conversion.

Key Points:

- Includes procedural model classes Cylinder, Quad, and Terrain.

- Provides prefab classes Draggable, Slider, and Sprite.
