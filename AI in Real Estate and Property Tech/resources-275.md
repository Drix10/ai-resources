### 🤖 SpriteCast adds 8-direction walk from one illustration

SpriteCast generates an 8-direction walk animation with 8 frames per direction plus 8 standing views from a single front-facing illustration. The pipeline uses OpenAI’s image model for drawing and Tripo 3D for body motion, camera angle, and per-frame shadows. A walking character costs about $3, broken down as $2.2 for drawing and $0.75 for Tripo credits. Users can request additional actions, props, or pixel-art versions at listed per-item prices.

Key Points:

- **Cost**: a walking character is $3 (drawing $2.2 + Tripo $0.75).

- **Output**: 8 frames per direction plus 8 standing views, all with matching 3D-generated shadows.

### 🤖 SyntaxSplat builds Gaussian splat scenes, adds .ply export

SyntaxSplat is a browser tool that turns signed distance field shapes into surfaces covered with small brush-stroke splats and bakes lighting into them. It lets rigid parts move each frame without rebaking and can export the current pose as a standard 3D Gaussian Splatting .ply file.

Key Points:

- Lighting baked into splats, including sky/ground hemisphere, ambient occlusion, sun shadows and point lights.

- Rigid parts can move each frame without rebaking; export current pose as .ply.

### 🤖 Modly – Open source desktop app for local image-to-3D mesh generation

Modly is an open source desktop application that turns images or prompts into 3D meshes on a local GPU. It runs on Windows, Linux and Apple Silicon macOS and supports AMD GPUs via ROCm without a separate ROCm installation. The app can smooth and decimate imported meshes and chain steps in workflows.

Key Points:

- Runs on Windows, Linux and Apple Silicon macOS.

- AMD GPUs work through ROCm on Linux and Windows with automatic detection and no separate ROCm install required.
