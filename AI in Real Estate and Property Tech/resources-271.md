### 🤖 AssetCat adds local UI and CLI for browsing game asset libraries

AssetCat is a local web UI and command-line tool that lets you browse game asset libraries and search by description, including style. It tracks licenses and AI provenance per bundle or pack, stores notes and tags in plain TOML files, and can copy selected assets into a project with a manifest of licenses and credit lines. The tool is read-only to the original library.

Key Points:

- Search by natural language description of images, with optional “more like this” queries

- Copy assets into a project while generating a manifest that includes licenses and credit lines

### 🤖 Pallaidium – free AI movie studio for Blender VSE

Pallaidium is a free, open-source AI movie studio integrated into Blender’s Video Sequence Editor that creates screenplay shots, images, animation, voices and music from lyrics or scene descriptions. It runs models locally by default, with optional external server support, and places generated media straight onto the timeline.

Key Points:

- Supports text-to-video, text-to-image, text-to-audio, text-to-music, and text-to-speech generation.

- Requires Blender 5.2+, CUDA 12.8, an Nvidia GPU with 6-16GB VRAM and at least 20GB of disk space.

### 🤖 gpt_image_playground adds annotatable reference images and branching edits

gpt_image_playground adds annotatable reference images and branching edits in a Web UI or Windows client. Users can paste, drag, or link images, then mark them with brushes, text, shapes, and a pixel eraser. The Agent keeps conversation context and calls image tools, creating branches for each edit. Batch prompts run in a queue or concurrently with progress and stop controls, and data can be exported as ZIP backups.

Key Points:

- Annotate reference images with brushes, text, shapes, and a pixel eraser.

- Branches created for each edit allow switching while keeping references in the current branch.

- Batch prompts can run in a queue or concurrently with progress and stop controls.

- Records and images stored locally can be exported as ZIP backups.
