### 🤖 InfiniSplat SplatAnything reconstructs 3D Gaussian scenes from multiple images

InfiniSplat’s SplatAnything (v3) reconstructs 3D Gaussian scenes from arbitrary numbers of images, with or without camera poses, using Gaussian spacing normalization. The project is free for academic use and requires registration for organizational use.

Key Points:

- Gaussian spacing normalization lets one model handle arbitrary scenes.

- Supports reconstruction from multi-camera rigs and 360° panoramas.

### 🤖 Godot-MCP connects AI agents to Godot editor

Godot-MCP lets Claude Code, Cursor, Codex and other AI agents inspect and edit a Godot project directly in the editor. Agents can read and modify scenes, nodes, resources, and scripts, build C# with compiler error feedback, validate GDScript, and receive viewport or node screenshots. Changes from a query apply all-or-nothing and can be undone with a single Ctrl+Z. The tool works in the editor or via a headless CLI.

Key Points:

- Agents can read and modify scenes, nodes, resources, and scripts.

- Query-driven edits are atomic and undoable with one Ctrl+Z.

### 🤖 Godot Shaders library released with demo scenes

Godot Shaders is a free open source collection of 2D, 3D and screen shaders, most of which include a demo scene. The repository provides an introductory animation of the shader pipeline and is being ported to Godot 4. Contributors are welcome.

Key Points:

- Library contains 3D dissolve, outline, shockwave, stylized fire, advanced toon, force field and other shaders.

- Shaders reside in the Shaders/ directory; demo scenes are in the Demos/ directory.

### 🤖 GAGAvatar – single-image 3D head avatar reconstruction and real-time animation

GAGAvatar turns a single image into a controllable 3D head avatar using Gaussian splatting and can animate it in real time with a driving image or video. The repository provides a pretrained model and instructions for retraining on custom data.

Key Points:

- Reconstructs a controllable 3D head avatar from a single image via Gaussian splatting.

- Supports real-time reenactment driven by another image or video, with pretrained model available.

### 🤖 openage – free Age of Empires engine clone announced

openage is a volunteer project creating a free clone of the Genie Engine with Python scripting and a mod-friendly nyan format. Gameplay is currently non-functional while the internal simulation is being built. Playing requires an original Age of Empires or Age of Empires II (including Definitive Edition) installation.

Key Points:

- Engine core written in C++26, scripting in Python 3, GUI with Qt6.

- Requires original game assets; the project does not include sounds or graphics.
