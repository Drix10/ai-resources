### 🤖 Neural Thickets – random logit bias matches weight perturbations gains

Neural Thickets perturbs every weight of a language model, keeps the best copies on a small labeled set, and lets them vote. A random bias added only to the output logits, leaving all other weights unchanged, matches or exceeds those gains across a diverse set of tasks.

Key Points:

- Random bias on output logits, with all other weights unchanged, matches or exceeds gains from full weight perturbations.

- Neural Thickets selects copies that score best on a small labeled set and uses voting.

- [Original post](https://x.com/kyutai_labs/status/2116303418218479954)

### 🤖 SingSync entry for open-source challenge released

SingSync is an entry for the open-source challenge that generates a potential full-length music video from one character image, one scene image and one sentence. It is built on ComfyUI using open-weight models and MIT-licensed code.

Key Points:

- Built on ComfyUI, open-weight models, MIT-licensed code.

- One character image, one scene image, one sentence can produce a full-length music video with an original song.
