### 🤖 VMware vCenter CVE-2026-123890 exploited by ARMORY CASTLE

VMware vCenter Server CVE-2026-123890 is an unauthenticated SRP-6a session key disclosure over DCE/RPC that allows remote admin authentication bypass. ARMORY CASTLE used the BONESAW utility in early September 2026 to exploit this flaw, exfiltrate the LMDB database and hijack the SAML Security Token Service.

Key Points:

- CVE-2026-123890 creates an authenticated session as administrator on vCenter.

- BONESAW leveraged the vulnerability to steal the LMDB database and create an SSO Administrator account.
