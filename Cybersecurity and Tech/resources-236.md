### 🤖 Devolutions RDM switching to Azure Artifact Signing

Devolutions RDM is moving from an EV certificate to Azure Artifact Signing and will update pinning to check publisher ID and Microsoft Root CAs. The change affects how custom certificate pinning validates signatures.

Key Points:

- Switching from an EV certificate to Azure Artifact Signing for Devolutions RDM

- Updating custom certificate pinning to check publisher ID and Microsoft Root CAs instead of a list of thumbprints of EV certificates
