### 🚨 MPTCP vulnerability allows full takeover of exposed Linux servers

MPTCP active on any unpatched Linux server with a single internet-exposed TCP port (e.g., HTTP or SSH) is vulnerable to complete takeover. The claim is highlighted in a quoted tweet stating the impact is “hard to overstate.”

Key Points:

- Any unpatched Linux server with one TCP port exposed to the internet and MPTCP enabled is vulnerable to complete takeover.

- MPTCP is active by default in many Go web servers.
