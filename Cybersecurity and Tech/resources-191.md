### 🤖 npm Package Security - Malicious Linux RAT

This article identifies a malicious ELF file discovered within the npm package "streak-metricazbd". Importing this package attempts to launch "REDSHELL," a Linux Remote Access Trojan (RAT).

Key Points:

• A malicious ELF was found in the npm package "streak-metricazbd".

• The ELF attempts to launch "REDSHELL", a Linux RAT.

• REDSHELL performs credential theft, remote execution, and persistence.
