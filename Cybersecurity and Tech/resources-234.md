### 🚨 SiteGuard Server Edition OS command injection exploited (CVE-2026-106931)

SiteGuard Server Edition web application firewall has an OS command-injection flaw (CVE-2026-106931) that lets attackers run commands as root or SYSTEM. The vulnerability resides in the statistics feature, which is enabled by default, and is being exploited in the wild. A patch replaces the statistics processing files, and administrators are advised to download diagnostic information before updating.

Key Points:

- CVE-2026-106931 enables OS command injection with root or SYSTEM privileges.

- **Affected versions**: SiteGuard Server Edition 2.20+ before 8.00 Update 5 (Apache, Nginx, IIS) and 2.20+ before 7.00 Update 6 (FreeBSD).
