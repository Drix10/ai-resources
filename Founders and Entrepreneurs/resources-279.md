### 🤖 Shirudo open-source Linux security tool blocks exploit before patch

Shirudo is an open-source Linux runtime that lets AI agents write eBPF shields to block exploits before patches are applied, without taking services offline. In a test a Codex-generated shield stopped a Java4Shell exploit against a running Elasticsearch instance.

Key Points:

- Open-source runtime lets AI agents write dynamic eBPF controls to shield systems from exploits.

- Codex-generated shield blocked a Java4Shell exploit without requiring a restart.
