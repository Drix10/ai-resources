### 🚨 Tether freeze $1.8B total, Circle $800M single wallet

Tether reports $1.8B frozen across three chains and Circle froze $800M in one wallet. About $880M remains freezable but not frozen, with large USDT balances on Ethereum and Tron addresses.

Key Points:

- **Total frozen amount**: $1.8B.

- Circle froze $800M in a single wallet.

- **Freezable but not frozen amount**: about $880M.

- Ethereum address 0x811f15855476156ebf86ba3b84fafb8ceaa4e84c holds 175M USDT, approved for swap.

### 🤖 Revolut designers move off Figma, LLM builds flows fast

Revolut's designers are leaving Figma and used an LLM given their design system code to create new flows, producing a live clickable interface. The approach was described as faster than other teams.

Key Points:

- Team gave an LLM Revolut's design system at the code level.

- Prompted the LLM to build new flows on top of that system and got a live interface they can click.
