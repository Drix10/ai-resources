### 🤖 invideo Remote Agents – AI video editor integration

invideo Remote Agents lets Claude, ChatGPT, Codex and other AI agents edit professional NLE timelines directly in the invideo editor. Setup uses MCP commands such as “claude mcp add --transport http --scope user invideo” or “codex mcp add invideo” and supports color correction, audio mixing, captions and export to Premiere, Final Cut or DaVinci.

Key Points:

- **Setup command**: claude mcp add --transport http --scope user invideo

- **Supported agents**: Claude, ChatGPT, Claude Code, Codex, Cursor can connect
