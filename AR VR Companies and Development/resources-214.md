### 🤖 Dot3D & Easy Street Draw - Crash Scene Diagramming

This article outlines a workflow for creating 2D diagrams from 3D crash scene maps using Dot3D and Easy Street Draw (ASD). The process integrates 3D scanning with 2D diagramming capabilities.

Key Points:

• Dot3D maps crash scenes in 3D, exporting orthophotos.

• Easy Street Draw (ASD) imports these orthophotos for 2D diagramming.

• Features include auto-drawing of roadways/buildings and vehicle positioning.

• The process allows detailed 2D diagrams to be overlaid on real scene data.

🚀 Implementation:
1.  Map a crash scene using Dot3D to capture 3D data.
2.  Export the 3D map as an orthophoto from Dot3D.
3.  Import the orthophoto into Easy Street Draw / ASD.
4.  Scale the image and create a 2D diagram over the scene.
