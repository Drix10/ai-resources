### 📊 Codex reduces Responses API data ~80% to 930KB from 7.48MB

Codex now pulls about 80% less data from the Responses API. An example thread dropped from 7.48MB to 930KB after compression.

Key Points:

- Data reduction ~80% measured on own threads

- **Example size**: 7.48MB → 930KB after compression

### 📊 ARTUS-2K dataset released with 2,041 indoor 3D scenes

ARTUS-2K is a dataset of 2,041 structured, lightweight, editable indoor 3D scenes from RGB video, with geometry and object placement aligned to the footage. It provides aligned geometry and object placement for each scene.

Key Points:

- 2,041 structured, lightweight, editable indoor 3D scenes.

- Geometry and object placement aligned to the RGB video footage.

### 📊 Power Glove rushed to market, no games released

Power Glove was used on PCs in the 90s because the tech was considered incredible, but it was rushed to market with no games that really used it and cancelled before any could be released. It was never meant to be used with normal NES games.

Key Points:

- Used on PCs in the 90s due to impressive technology.

- Rushed to market, no supporting games released, cancelled before any could appear.

🔗 Resources:

- [Original post](https://x.com/tacolamp/status/2126389718095192505)
