### 🚀 Neural Render Proxies for Interactive and Differentiable Lighting

Neural Render Proxies enable differentiable relighting of static scenes at interactive rates, achieving 30-60 Hz frame rates. The method decouples path sampling from emission computation using a single light-agnostic render pass. A scene-specific lightweight neural network learns light transport from any location to any pixel. It works with non-differentiable production renderers and requires minimal memory during inference.

Key Points:

- Interactive relighting achieved at ~30-60 Hz while closely approximating ground-truth path tracing.

- Scaling depends on resolution and number of light sources and parameters, independent of scene and appearance complexity.

- [Original post](https://x.com/ssh4net/status/2121590833887789319)
