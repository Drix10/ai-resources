### 🤖 Unreal Engine 5.9 MegaJam Preview released with agentic workflow features

Unreal Engine 5.9 MegaJam Preview is the first Unreal Engine release built primarily with agentic workflows and adds experimental features such as expanded Unreal MCP toolsets, AI coding agents in the editor, AI-assisted content creation, and browser-based project runs. The preview was developed in about a week and includes a short QA pass, with known issues listed for Web builds on Mac, Linux, and mobile.

Key Points:

- Unreal MCP now launches automatically, expands toolsets for rendering, source control, profiling, debugging, gameplay testing, geometry, audio, UI, and level creation, and integrates with Lore and Fab toolsets.

- Unreal Assistant lets preferred AI coding agents (Claude Code, Codex, Cursor, OpenCode) operate in the in-editor assistant panel connected to Unreal MCP.
