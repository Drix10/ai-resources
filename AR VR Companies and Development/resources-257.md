### 🤖 Babylon.js Fur Material – volumetric fur via stacked shells

Babylon.js provides a Fur Material that creates volumetric fur by rendering multiple offset shells of a mesh. The effect is driven by a runtime‑generated fur texture and can be customized with length, spacing, density and gravity parameters. The library includes functions to generate the texture, create shells, and adjust material properties.

Key Points:

- FurMaterial.FurifyMesh(myMesh, 30) returns an array of shell meshes; the first element is the original mesh.

- Material properties include furLength, furAngle, furColor and furGravity (e.g., new Vector3(0, -1, 0)).
