Fable 5.2 was tested with one-shot prompts without human feedback. The run used only scratch models, sounds and textures and cost about $550 at API pricing. It generated roughly 2.7M output tokens and consumed 445M input tokens in 8 hours.

Key Points:

- **Cost**: ~$550 at API pricing

- **Output tokens**: ~2.7M

- **Input tokens**: 445M

- **Duration**: 8 hours
