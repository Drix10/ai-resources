### 🤖 Amortized Bayesian inference - trains once, fast posterior

Amortized Bayesian inference trains a network once on simulations and returns posteriors in a single forward pass. It contrasts with MCMC where fitting the same model hundreds of times scales cost with every fit.

Key Points:

- Fitting the same model hundreds of times? With MCMC, the cost scales with every fit.

- Amortized Bayesian inference trains a network once on simulations, then returns posteriors in a single forward pass.
