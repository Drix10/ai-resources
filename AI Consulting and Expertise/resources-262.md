### 🤖 Valibot – Open source type‑safe schema library announced

Valibot is an open source, type‑safe schema library. Its modular design is tree‑shakeable, allowing only the validation code you use to be shipped and keeping bundles small. The maintainer, @FabianHiller, actively contributes to the TypeScript ecosystem.

Key Points:

- Open source, type‑safe schema library

- Modular, tree‑shakeable design reduces bundle size

### 📊 SWE-CC measures repository rule compliance for coding agents

SWE-CC is a benchmark created by researchers to evaluate how coding agents follow repository policies. It includes 823 machine‑checkable policies drawn from 12 open‑source repositories. Agents were run on 500 software tasks to assess rule adherence.

Key Points:

- **Policies**: 823 machine‑checkable rules extracted from 12 repos.

- **Evaluation**: Agents tested on 500 software tasks.
