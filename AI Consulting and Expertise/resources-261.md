### 🤖 Glimpse screenshot search tool announced for Windows

Glimpse lets you search screenshots on Windows by text or visual similarity. It runs locally with a global hotkey Win+Alt+S. The tool is open source, private and requires no admin or .NET install.

Key Points:

- Search latency reported as 2 ms in the announcement.

- Benchmarks show a 21 ms median query time on a laptop with 10,038 indexed images.
