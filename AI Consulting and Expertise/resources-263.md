### 📊 Agent loop vs structured call cost for scoring bids

Scoring 21 bids with an agent loop cost $1.58. A single structured call scored 268 bids for $0.19. The cost difference is about 100× per bid, with the model swap accounting for only ~3× and the rest due to loop re‑reading its own context. For classification, architecture beats model choice.

Key Points:

- **Cost**: 21 bids via agent loop = $1.58; 268 bids via structured call = $0.19.

- **Cost per bid**: ~100× cheaper with structured call; model swap explains ~3×, loop context re‑reading explains remainder.
