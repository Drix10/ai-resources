### 🤖 Sand3D Organic open source 10K organic 3D assets as code

Sand3D Organic is now open-source and adds 10,000+ organic 3D assets written as code to the existing 100,000 objects in Sand3D. Each asset is a readable Python program with parameters for species, style and season. The library is available on Hugging Face and GitHub.

Key Points:

- 10,000 organic 3D assets written as code, joining 100,000 objects already in Sand3D.

- Each asset is a single Python file; parameters include species name, style argument, and season setting.
