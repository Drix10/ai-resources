### 🤖 Gauzilla Pro adds GeoAI object detection and segmentation

Gauzilla Pro features GeoAI that can detect any object with high precision from a top-down view. It can annotate, move, copy, delete, and export detected objects. Describing an object in natural language triggers automatic 3-D segmentation. The AI adds geospatial context to scenes.

Key Points:

- **Feature**: GeoAI detects any object with high precision from a top-down view.

- **Capability**: Natural-language description automatically segments the object in 3D.
