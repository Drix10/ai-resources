### 🤖 Seedream 5.5 – live on Pixazo API with 2K text-to-image, 10-image edits

Seedream 5.5 is now available on the Pixazo API, offering text-to-image generation up to 2K resolution and image edits using up to 10 reference images. It also provides transparent-background PNGs and layer separation into a base plus up to 19 transparent layers, priced from $0.02 per 1.5K image.

Key Points:

- Text-to-image generation supports resolutions up to 2K.

- Image editing accepts up to 10 reference images.
