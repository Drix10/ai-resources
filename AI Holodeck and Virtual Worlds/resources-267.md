#### Article 1: PlayCanvas Engine 2.23.0

PlayCanvas Engine 2.23.0 is a significant update to the free and open-source web graphics engine. This release brings up to 3.8× faster rendering, an all-new UI, and several new features such as nearest-first splat streaming and bloom threshold.

Key Points:


- **


- **Nearest-First Splat Streaming**: This feature allows for more efficient rendering of complex scenes by prioritizing the rendering of nearby objects.

- **Bloom Threshold**: This feature allows for more control over the rendering of bright objects, such as explosions or fire.

- **MiniStats + Inspector**: These features provide more detailed information about the performance of the engine and the objects being rendered.


**Actionable Takeaway:** If you're using PlayCanvas Engine, consider updating to version 2.23.0 to take advantage of the new features and performance improvements.
