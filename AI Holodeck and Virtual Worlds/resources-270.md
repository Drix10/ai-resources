### 🤖 WorldBox sandbox adds spatial memory to Opus 5.5 and Astra

WorldBox is Enactra’s sandbox that gives agents spatial memory of their Minecraft world. Opus 5.5’s progress increased by 133% with this memory. Astra’s progress increased by 50% with this memory.

Key Points:

- **Opus 5.5**: +133% progress gain

- **Astra**: +50% progress gain

### 🚀 paper MCP adds list_resources and rename features

paper MCP now uses list_resources instead of list_files and includes folders. It also adds rename_resources for files and folders and rename_pages for pages in a file.

Key Points:

- list_files becomes list_resources and includes folders

- added rename_resources to rename files and folders

- added rename_pages to rename pages in a file

### 🤖 ZenRowsHQ Agent Storefront pricing announced

ZenRowsHQ released an Agent Storefront through ZeroClick that can fetch data from sites with anti‑bot measures or JavaScript rendering. The service costs $0.0005 per standard page. Failed requests are not charged.

Key Points:

- **Pricing**: $0.0005 per standard page.

- **Billing**: No charge for failed requests.
