### 🤖 Daydream Music Generation API launches with royalty-free songs and stems

Daydream Music Generation API lets developers send a text description and receive an MP3, a WAV, and five separate stems. The API includes Unity and Godot examples. Free tier offers ten songs per month; paid tier provides 500 songs for $4.

Key Points:

- API returns a royalty-free song and its five stems as MP3 and WAV files.

- Free tier allows 10 songs per month; $4/month tier provides 500 songs.
