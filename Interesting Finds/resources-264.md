### 🤖 Flight Tracker – live split-flap board announced

Flight Tracker is a live split-flap display that shows every plane within a chosen radius, updating every 30 seconds. It is currently in alpha and access is granted via a waitlist while the app moves to production after code review and security checks.

Key Points:

- Updates every 30 seconds with plane type, destination, altitude, speed and direction.

- Users enter a US ZIP code and select a radius of 5–20 miles.
