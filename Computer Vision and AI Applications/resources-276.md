### 📊 Camera3R – Feed-Forward 3D Reconstruction adapts with 0.5% extra parameters

Camera3R is a low-rank adaptation framework that extends perspective-pretrained 3D reconstruction networks to heterogeneous camera models. It adds only 0.5% additional parameters and requires less than a day of training while preserving original performance on perspective inputs. Code is released publicly.

Key Points:

- Adaptation adds 0.5% extra parameters to the base model.

- Training time for adaptation is under one day.

### 🤖 Prompt2Echo launches unified multi-view echo segmentation model

Prompt2Echo introduces a single model that segments cardiac structures across multiple echocardiographic views using structured text prompts. It employs a Dynamic Image-Text Alignment (DyITA) module to route decoder features per view. Experiments show it matches or exceeds view-specific specialists and state-of-the-art universal models while using less computation.

Key Points:

- DyITA integrates a differentiable routing mechanism and token differential operators to modulate decoder features for the requested view and target structure.

- Code for Prompt2Echo is released publicly.
