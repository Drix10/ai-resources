### 🤖 x86 formal verification first machine-checked proof announced

x86 formal verification is coming with the first published machine-checked proof of a security property for the end-to-end execution of a Linux process running an x86 binary statically linked against glibc. The work is a joint research project with Zellic.

Key Points:

- First published machine-checked proof of a security property for end-to-end execution of a Linux process running an x86 binary statically linked against glibc.

- Joint research project with @zellic_io.

### 🤖 Recurrent VLMs - prune-then-loop strategy paper

Recurrent VLMs - prune-then-loop strategy paper introduces a method to turn pretrained VLMs into recurrent models. The work is released as an arXiv preprint with a project page.

Key Points:

- **Paper**: arXiv:2610.22075
