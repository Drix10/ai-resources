### 🤖 Autoregressive View Model streams virtual camera views, demo released

Autoregressive View Model (AVM) streams 2D views from a virtual camera using synchronized feeds and autoregressive generation. The demo shows cameras stopping recording before the virtual camera is chosen, and AVM can generate short blocks with a few denoising steps per block.

Key Points:

- AVM generates short blocks autoregressively, allowing each block to follow a new camera query.

- Reality View runs a ~1B-parameter diffusion model on half of one TRIP accelerator on Tesla’s AI4 chip.

- [Original post](https://x.com/jensenzhoujh/status/2124520430648115283)

### 🚀 Shirudo runtime launches dynamic eBPF shields

Shirudo runtime launches dynamic eBPF shields to defend Linux systems without downtime. It is open source, built by Cisco with OpenAI, and aims to let AI agents write and deploy shields while services run.

Key Points:
