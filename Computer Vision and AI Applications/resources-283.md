### 🤖 World Models as Latent Action Models launch 3.8B PAWlicy

World Models as Latent Action Models introduces a 3.8B PAWlicy model that reaches 93.6% average success on RoboTwin 2.0. The paper shows native latent actions beat existing LAMs on the LARY benchmark for classification and regression. It uses a pretrained video diffusion transformer as both inverse and forward dynamics with learnable registers. All training uses public video data and a public world model.

Key Points:

- 93.6% average success rate on RoboTwin 2.0 with the 3.8B PAWlicy model.

- Native latent actions outperform existing LAMs on the LARY benchmark in action classification and control regression.

### 🤖 GlanceNav: Efficient Vision-and-Language Navigation announced with 71.9% success

GlanceNav is a streaming vision-and-language navigator that uses a constant-size memory and runs at 104 ms per step, achieving 71.9% success on R2R-CE validation unseen. It introduces Counterfactual Rewind to credit decisions by rewinding rollouts and correcting actions.

Key Points:

- Constant-size memory keeps the cost per step fixed and allows training on whole episodes with the same memory as at inference.

- A 4B GlanceNav reaches 71.9% success on R2R-CE and 73.6% on RxR-CE val-unseen, running at 104 ms per step.
