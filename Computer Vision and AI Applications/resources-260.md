### 🤖 T2-z world model improves robot slip detection to 73% success

T2-z (Stanford) uses a 32-number environment code to infer table slipperiness from a single poke, raising success from 34% to 73%. Test-time pokes adjust only the code while network weights stay frozen, and real-robot tasks show friction prediction improving from 0% to 62.5% and stick balance from 20% to 83%.

Key Points:

- 32-number “environment” code tunes only at test time, weights remain frozen.

- Best performance on all 11 tasks versus 4 baselines, with real-robot friction prediction 0% → 62.5% and stick balance 20% → 83%.

### 🤖 RustGIS adds Moon, Mars and 12 celestial bodies

RustGIS now maps the Moon, Mars and other worlds, offering 12 selectable celestial bodies. The basemaps come from OpenPlanetaryMap and USGS Astrogeology and are served through the opengeos tile service.

Key Points:

- **12 bodies**: Earth, Moon, Mars, Mercury, Venus, Io, Europa, Ganymede, Callisto, Titan, Pluto, Charon.

- Measurements use the selected body's radius, so a kilometer on Mars is a Martian kilometer.
