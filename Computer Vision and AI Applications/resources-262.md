### 📊 FOMI Interface released, 29% more demos than UMI

FOMI Force-feedback Manipulation Interface released, achieving 29% more successful demos than UMI in the same time. It adds tactile feedback without force sensors or motors and π0.5 fine-tuned on about an hour of FOMI data per task reaches 78.4% average success on four contact-rich tasks.

Key Points:

- 29% more successful demos than UMI in the same time.

- π0.5 fine-tuned on about an hour of FOMI data per task reaches 78.4% average success on four contact-rich tasks.

### 🤖 Agentic World Action Models AW-0 achieves 71.1% on real tasks

Agentic World Action Models AW-0 generates code, video predictions, and robot actions together, reaching a 71.1% average rubric score on eight real-world manipulation tasks. The model combines a code expert, video expert, and action expert inside a mixture-of-transformers architecture.

Key Points:

- AW-0 50.7% average success on RoboTwin 2.0, vs 41.3% for π0.5.

- 71.1% average rubric score across eight real tasks, vs 46.0% for the strongest baseline.

### 📊 Data Schedules and LR Schedules ties schedule to LR

Data Schedules and Learning Rate Schedules paper links optimal data schedule to the learning rate schedule. The authors note that the answer to placing math data early or late flips with the LR schedule.

Key Points:

- Data mixing ratio of midtraining data changes from 0 to 1 in the middle of training.

- Optimal data schedule depends on the learning rate schedule, per the new paper.
