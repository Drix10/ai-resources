### 🚀 Beam shipping with DFlash2 3× faster decode

Beam is now released with open weights under Apache 2.0, powered by DFlash 2 which makes model decode up to 3× faster with zero quality loss. The release includes weights, tokenizer, reference implementation, and BF16, FP8, NVFP4 weight formats plus a DFlash2 drafter.

Key Points:

- **Decode speed**: up to 3× faster with zero quality loss using DFlash 2.

- **Release assets**: weights, tokenizer, reference implementation, BF16, FP8, NVFP4 weights, and a DFlash2 drafter.
