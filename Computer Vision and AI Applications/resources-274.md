### 🤖 BayesCrop real-time probabilistic multi-crop video reframing announced

BayesCrop introduces a real-time probabilistic framework for multi-crop video reframing, achieving 112 FPS at the default operating point. It models crop preferences with a two-component isotropic Gaussian mixture and uses an anchor-and-propagate strategy with motion vectors. Experiments show competitive single-output localization and high multi-crop reference coverage on several benchmarks. The paper is accepted at WACV 2027.

Key Points:

- Real-time throughput of 112 FPS at default operating point

- Uses a two-component spatially isotropic Gaussian mixture for crop position and scale

### 📊 Active VLM-TTA (ACTOR) improves VLM test-time adaptation

Active VLM-TTA introduces ACTOR, a training-free plug-in that routes uncertain samples for label query or memory correction. It works under a future-only label constraint and adds negligible inference overhead. ACTOR consistently improves strong VLM-TTA baselines on ResNet and ViT backbones across ten cross-domain benchmarks.

Key Points:

- ACTOR is a training-free module that selects between base prediction, label query, and memory-based correction using a consistency-and-reliability check.

- ACTOR shows consistent gains on ten cross-domain benchmarks and an ImageNet domain-transfer benchmark with negligible overhead.
