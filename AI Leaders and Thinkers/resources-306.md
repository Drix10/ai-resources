### 🤖 Tessera – 25 free themes for Claude Code released

Tessera provides twenty-five free themes for the Claude Code desktop app, each with colors, a scene that moves while Claude works and stops on answer. Themes are installed via the btahir/tessera plugin in the desktop app or with a terminal command. Contrast ratios range from low (8.4-9.6:1) to high (15.9-17.5:1) and include sound options.

Key Points:

- 25 free themes are offered for Claude Code, each with a moving background that stops when the answer lands.

- Install the tessera plugin from the btahir/tessera marketplace in the desktop app or with “/plugin install tessera --marketplace btahir/tessera”.

- **Contrast levels**: two low (8.4-9.6:1), twenty-one standard (10.3-13.2:1), two high (15.9-17.5:1).

### 🤖 Jev token pricing charges state tokens once per call

Jev charges input tokens as state plus the sum of all questions. State tokens are billed only once per call, even when multiple questions run in parallel. Two questions in a single call cost more than a single question.

Key Points:

- **Billing formula**: state + (sum of all questions)

- State tokens charged once per call regardless of parallel questions

### 🤖 OpenAI Wallet pass-through design and agentic commerce launch

OpenAI Wallet is a pass-through wallet that never holds funds and uses a one-time token from your card at checkout. It enables agent-based commerce where merchants need no integration and agents forward real IP, timezone and locale to payment processors.

Key Points:

- No new payment rails; add a card once (mobile only) and approve with Face ID, then a one-time token is used at checkout.

- Wallet holds $0; it is a pass-through network token on your own card, OpenAI never touches the money or becomes merchant of record.
