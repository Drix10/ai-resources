### 🤖 Kronos – open-source foundation model for candlestick charts, new model zoo released

Kronos is an open-source foundation model for financial candlestick charts that forecasts next bars from price history. The page adds a model zoo with four variants, including Kronos-mini (4.1M parameters) and Kronos-base (102.3M parameters), and notes a max context length of 512 tokens for the small and base models.

Key Points:

- **Stars**: +2,653 ★ this week.

- Model zoo includes Kronos-mini (4.1M params) and Kronos-base (102.3M params).

### 🤖 manga-generator new open-source tool announced

manga-generator is a new open-source tool released under MIT code that turns a novel into a manga. It processes text through script, storyboard, image generation and lettering, then outputs a PDF with speech bubbles kept separate from the art.

Key Points:

- **License**: MIT code

- **Output**: PDF with separate speech bubbles
