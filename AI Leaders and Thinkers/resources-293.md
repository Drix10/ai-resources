### 🤖 OpenTTD-Bench released, benchmark for frontier LLM agents

OpenTTD-Bench released as a benchmark for measuring frontier LLM agents on real-time, long-horizon tasks. It uses the OpenTTD business simulation game.

Key Points:

- **Benchmark**: measures frontier LLM agents on real-time, long-horizon tasks.

- **Basis**: based on OpenTTD where models run competing transportation companies to maximize profit.

### 🤖 Radix PBR Gaussian splats demo with real-time lighting

Radix demo shows PBR Gaussian splats that store base color, roughness, metalness and a normal from the source mesh, enabling real-time lighting. The splats are rendered with a fun lighting demo.

Key Points:

- PBR Gaussian splats store base color, roughness, metalness and a normal from the source mesh.

- The splats can be lit in real time.
