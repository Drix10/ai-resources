### 📊 Claude Code PRs double, revert share down 40%

Key Points:

- Merged PRs more than doubled from June to September.

- Share reverted fell by more than 40%.

### 🚀 Muxin – one app for all computers launched

Muxin is a free open-source app that runs AI coding agents on Macs, Linux servers, Windows PCs and cloud machines from one window. It lets agents use the same interface across all machines.

Key Points:

- Runs AI coding agents on Macs, Linux servers, Windows PCs, cloud machines.
