### 🤖 End2End pipeline wins first prize at Junction2026

### 🤖 Hebbian RUA public beta launch with robot control

Hebbian RUA public beta lets a frontier model get a goal, camera views, and robot tools to control a robot. It enables agents to write and run code against a robot's controller and retry when something goes wrong.

Key Points:

- Frontier multimodal models can look at a camera feed, write and run code against a robot's controller, and check their own progress, retrying when something goes wrong.

- Hebbian RUA in public beta takes a goal, camera views, and a set of predefined robot tools, and controls a robot to perform the task.
