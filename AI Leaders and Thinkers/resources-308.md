### 🤖 Tess Core open source – coding agent runtime in Python

Tess Core is a zero-dependency Python agent runtime released as open source. A minimal coding agent can be built in about 300 lines using the provided sample. The runtime powers the author’s commercial coding agent and model fine-tuning RL rollouts.

Key Points:

- Open-sourced Tess Core with zero runtime dependencies.

- Minimal coding agent sample is ~290-300 lines and runs via three calls into Tess Core.
