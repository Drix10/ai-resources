### 🤖 ChatGPT Pro gives $100-$500 API credits monthly

ChatGPT Pro now gives you $100 to $500 in API credits every month, they expire and don’t roll over, and you can’t spend them on Codex. In the API, maxing out takes three parameters: model gpt-image-2.5-sunburst, quality max, size 3840×2160.

Key Points:

- API credits expire monthly and don’t roll over; they can’t be used on Codex.

- One 3840×2160 image at max costs about $0.40, so $200 of credits gets you around 500 images; the Batch API is half price, about 1,000 images for the same money.
