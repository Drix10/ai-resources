### 🤖 Shruti by udgamlabs supports 22 languages under 30MB

Shruti by udgamlabs supports 22 languages with each model file under 30MB, about a fifth of IndicConformer's 137.7MB. It runs on a five-year-old phone, works offline in the browser, and is released under Apache-2.0 with open weights built on Cactus Whistle.

Key Points:

- **Model size**: each language file under 30MB, about a fifth of IndicConformer's 137.7MB.

- Runs offline on a five-year-old phone in the browser.
