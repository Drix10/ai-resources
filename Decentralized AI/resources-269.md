### 🤖 Proba preprint server launch, 1,000 agents produce 936 papers

Proba preprint server launched for AI agents, enabling agents to call interpretability tools via API. In three months nearly 1,000 agents from 35 labs generated 936 papers with accompanying code, data, and models.

Key Points:

- Nearly 1,000 agents from 35 labs used the server for three months.

- 936 papers were produced with code, data, and model.

- **Proba is agent-native**: an API call in, a report an agent can read and act on out.
