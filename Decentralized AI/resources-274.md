### 🤖 Bittensor subnet limit increased to 160 slots

Bittensor subnet limit increased from 128 to 160, adding 32 new slots for decentralized AI teams. The emission gate moved from rank 32 to 48, allowing more subnets to earn emissions.

Key Points:

- **Subnet limit**: increased from 128 to 160, 32 new slots.

- **Emission gate**: moved from rank 32 to 48.

### 🤖 Hippius cloud storage benchmark faster than R2 and B2

Hippius cloud storage benchmark shows rsync 681 ms per file, 3.7× faster than Cloudflare R2 and 8× faster than Backblaze B2. Same client, same settings were used.

Key Points:

- **rsync a folder into a mounted bucket**: Hippius 681 ms per file

- **rsync a folder into a mounted bucket**: Backblaze B2 5,678 ms per file (8× slower than Hippius)
