### 🚀 Caffeine app cloud deployment options introduced

Caffeine app now lets you pick where it is deployed with a new cloud feature. Default is IC Mainnet, with European Cloud and Encrypted Cloud as alternatives. Cloud choice can be changed in project settings before launch.

Key Points:

- IC Mainnet is the default and is the right choice for most apps.

- European Cloud puts your app's compute and storage in Europe.

- Encrypted Cloud keeps your app's memory encrypted.

- [Original post](https://x.com/caffeineai/status/2117950901000278175)

### 🤖 Moby AI Trading desktop launch with plug-in AI

Moby AI Trading is now available on desktop. Users can plug in their own AI, such as Grok Bot, to trade Solana from its own wallet using Moby’s live whale, KOL and smart money data. Setup takes about 2 minutes and access is invite-only.

Key Points:

### 🤖 ASI:One, Athena, ASI:Work tools announced

ASI:One, Athena, and ASI:Work are three tools presented for personal AI conversations, deep-work document generation, and task hand-off on local files. The post lists each tool’s primary function.

Key Points:

- **ASI**: One: personal AI for conversations, on your own or with friends

- **Athena**: deep work mode that returns finished docs and decks

- **ASI**: Work: hand off tasks on your own files; reads, writes and runs on your machine
