### 📊 HBM4 bandwidth increase to 1.5+ TB/s with 2,048-bit bus

HBM4 reaches over 1.5TB/s per stack using a 2,048-bit bus, while HBM3e provides about 1.2TB/s on a 1,024-bit bus. Per-pin data rate stays near 6.4 Gbps for both generations. Quantization (FP8, FP4) can double or quadruple throughput on the same chip.

Key Points:

- Per-pin data rate is about 6.4 Gbps on both HBM3 and HBM4.

- HBM4 uses a 2,048-bit bus, giving per-stack bandwidth of 1.5+ TB/s; HBM3e uses a 1,024-bit bus, giving about 1.2TB/s.

- FP8 provides roughly a 2× throughput multiplier over FP16 on the same chip.

- FP4 provides roughly a 4× throughput multiplier over FP16 on the same chip.
