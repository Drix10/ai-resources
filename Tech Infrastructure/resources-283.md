### 🤖 Anthropic expands Claude enterprise lineup, adds legal and code tools

Anthropic is adding enterprise products to Claude, including Claude for Legal with contract-review capabilities and Claude Code Review. The company announced Claude Sheets, Whiteboards, Data and previewed Claude Meetings. Spellbook reports roughly 530,000 monthly contract reviews using Claude-powered agents.

Key Points:

- Claude for Legal launched, overlapping with Spellbook’s contract-review business.

- Claude Code Review announced; Anthropic also introduced Claude Sheets, Whiteboards, Data and previewed Claude Meetings.
