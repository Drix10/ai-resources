### 🤖 Cognition Devin Bots build Android app in 44 days

Cognition’s Devin Bots built an Android version of Devin in 44 days, merging 1,134 pull requests and writing 344,651 lines of Kotlin. The overseeing engineer sent 183 messages, with no messages on 22 of the days.

Key Points:

- **Pull Requests**: 1,134 merged, 344,651 Kotlin lines, 1,217 tickets closed in 44 days.

- **Engineer messages**: 183 total, none on 22 days.

### 🤖 WebMCP added to static Hugo site on GitHub Pages – 562 token query vs 99,000 token HTML
