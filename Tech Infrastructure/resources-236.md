### 🚀 Server-Side Rendering for Dashboards

Server-side rendering (SSR) was chosen over client-side rendering for our dashboard in 2023. Everyone wanted a React SPA. Modern. Fast. Sexy. We went with server-rendered HTML and minimal JavaScript. Why: 

- **Dashboard Users on Slow Corporate Networks**: Server-side rendering ensures that the initial HTML is generated on the server, which is beneficial for users on slow corporate networks where client-side rendering might be slow or unreliable.
- **Time to First Meaningful Paint (TTFMP)**: Server-side rendering allows for faster TTFMP, which is essential for a good user experience. By rendering the initial HTML on the server, we can ensure that the user sees the content sooner.
