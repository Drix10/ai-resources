### 📊 Anthropic software factory sensor metrics defined

Anthropic describes verification as the sensor in an agentic software factory and defines latency, fidelity, and bandwidth as key properties. It reports merging 2,500 code changes per day in May and over 30,000 per day by September. The sensor properties guide how fast and accurate the delivery loop can operate.

Key Points:

- **Latency**: time from a change being ready to a verified result in a production-like environment.

- **Fidelity**: measured by escape rate, the share of failures found after merge.

- **Bandwidth**: number of concurrent sensor readings the system can handle.
