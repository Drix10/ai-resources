### 📊 TPU Sync cuts inference latency up to 90%

TPU Sync is an open-source C++ framework that moves KV-cache data across memory tiers and claims more than 90% reduction in KV-cache transfer latency and time to first token. Google reports up to 90% cut in TTFT for a 480-billion-parameter model and 223GB/s host-to-device throughput on Ironwood TPU hosts.

Key Points:

- KV-cache transfer latency reduced by over 90% in some tests.

- Combined host-to-device and device-to-host throughput reached 223GB/s per Ironwood TPU host.

### 🤖 Appwrite Activity reasons – shows why each change was made

Appwrite Activity now includes a Reason column that displays a short note for every change. The MCP server requires a one-line reason for each AI agent write, and the CLI and any client can supply a reason via a flag, environment variable, or X-Appwrite-Reason header. Reasons are limited to one line, up to 256 UTF-8 characters.

Key Points:

- Reason column added to Activity; each event shows the full text in its details.

- CLI commands accept --reason or the APPWRITE_REASON environment variable; the flag overrides the variable.

🔗 Resources:

- [Original post](https://x.com/appwrite/status/2120802511263334514)
