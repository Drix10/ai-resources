### 🚀 Dropbox acquires Tigris for $350M to launch DBX Agent Cloud

Dropbox announced a $350 million acquisition of Tigris to power its upcoming DBX Agent Cloud service, which will let developers buy S3-compatible object storage directly from Dropbox. Tigris provides an S3-compatible platform with no egress fees and has customers such as Amplified, Railway, Runpod and Replicate.

Key Points:

- **Acquisition price**: $350 million for Tigris.

- DBX Agent Cloud will initially offer object storage built on Tigris technology.

- Tigris raised a $25 million Series A round in October 2025.

- Dropbox moved >90% of user data off AWS S3 to its Magic Pocket system in 2015.
