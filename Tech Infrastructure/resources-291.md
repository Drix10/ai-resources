### 🤖 Azure SQL Hyperscale automatic index compaction with ALTER DATABASE command

Azure SQL Hyperscale can turn on automatic index compaction using a single ALTER DATABASE command. The feature runs background tasks that compact sparse pages to reduce logical reads and keep dashboards responsive.

Key Points:

- Automatic index compaction enabled by one ALTER DATABASE command.

- Background tasks compact sparse pages to cut logical reads and keep dashboards responsive.
