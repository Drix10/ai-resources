### 🤖 Oura sleep detection blocks morning recovery buffer on calendar

Oura logs a short night and creates a recovery window on the next morning’s calendar. The buffer prevents meetings from being scheduled during that time. Users can set the definition of “short” sleep and the duration of the buffer.

Key Points:

- **Feature**: Short‑night detection creates a blocked recovery window.

- **Configurable**: Users define what counts as “short” and how long the buffer lasts.
