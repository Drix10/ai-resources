### 🤖 Cloud Run writable filesystem memory limit causes crash with 1 GiB video

Cloud Run’s writable filesystem lives in memory, so written files count toward the memory limit. A 1 GiB video download crashes a 512 MiB container. Ephemeral disks provide dedicated storage separate from memory.

Key Points:

- Writable filesystem resides in memory and counts toward the memory limit.

- Downloading a 1 GiB video into a 512 MiB container crashes it; Ephemeral disks separate storage from memory.

### 🤖 Go 1.28 allows omitting type in composite literals

Go 1.28 lets you omit the type in a composite literal when the context infers it, enabling syntax like var p Point = {1, 2}. The change closes a proposal that started in 2015 and was finally resolved after 11 years.

Key Points:

- var p Point = {1, 2} is now valid syntax

- var ptr *Point = {1, 2} is now valid syntax

- Issue proposed in 2015 was closed after 11 years
