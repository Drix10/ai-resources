### 🤖 Vork 3D engine 2,500-token API renders 1M birds in 97 s

Vork 3D engine with a 2,500-token core API renders a simulation of 1 million birds in 97 seconds on an NVIDIA L4 GPU. It claims 2× token efficiency versus Blender, Unreal Engine, Houdini and up to 24× faster rendering, using Rust and Slang on Metal/Vulkan.

Key Points:

- **Token efficiency**: 2x more token-efficient vs Blender, Unreal Engine, Houdini

- **Benchmark**: 1 million birds rendered in 97 s on one NVIDIA L4 GPU; Blender EEVEE takes 31 minutes
