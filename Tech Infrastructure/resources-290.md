### 🤖 OpenCode Browse Rust rewrite cuts memory 97%

OpenCode Browse was rebuilt in Rust for $60, producing a 4.3MB binary and reducing per-connector memory from roughly 190MB to 5.6MB (~97%). The Rust version replaces Playwright and Patchright with a custom implementation using Chrome DevTools Protocol and embeds QuickJS.

Key Points:

- **Binary size**: 4.3MB vs 53–64MB for the previous Node version

- **Memory per connector**: ~190MB down to 5.6MB, a ~97% reduction
