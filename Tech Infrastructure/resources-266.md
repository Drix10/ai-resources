### 🤖 Cloudflare absorbs Deno team, winds down Deno runtime

Cloudflare is acquiring the entire Deno team and will cease development of the Deno standalone runtime. The open‑source Celld project will be merged with Cloudflare’s workerd runtime, and Deno Deploy will end in six months while the Deno runtime receives maintenance for a year.

Key Points:

- **Team**: Cloudflare is adding the whole Deno engineering team.

- **Timeline**: Deno runtime gets monthly maintenance and security updates for one year; Deno Deploy ends in six months with migration help.

### 🤖 Clef-omni adds audio, video, text and image input; Clef-flash cheaper

Clef-omni is out and adds audio and video input, plus text and images. Cloudflare teams are using it to find PII, detect malicious domains, and the docs repo to close spam issues. Clef-flash is now cheaper at $0.038 per M input tokens.

Key Points:

- **Feature**: Clef-omni adds audio and video input, plus text and images.

- **Usage**: Cloudflare teams use it for PII detection, malicious domain detection, and closing spam issues.
