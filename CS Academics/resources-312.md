### 🤖 TwIL-8B open-source release, 8.8B params, 93% coding frontier

TwIL-8B is open-sourced with 8.8 billion parameters and reaches 93% of frontier performance on coding benchmarks and 92% on instruction following. The post shares Andrej Karpathy’s five-point thesis on small LLMs and claims a 1B-parameter core can capture most intelligence.

Key Points:

- TwIL-8B has 8.8 billion parameters.

- It achieves 93% of frontier performance on coding benchmarks.

- It achieves 92% of frontier performance on instruction-following benchmarks.

- Karpathy’s thesis lists five arguments that a ~1B-parameter core can contain the cognitive core of LLMs.
