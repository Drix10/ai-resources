### 🤖 ReadyNeuro dataset released, 16TB of fMRI shards

ReadyNeuro provides 16TB of training-ready fMRI shards from the OpenNeuro corpus, covering 30K subjects, 837 studies, and 1,300 tasks. The authors also share training and evaluation code plus model weights for their foundation model. They report that native space and minimal preprocessing steps have little effect on downstream model performance.

Key Points:

- 16TB of training-ready shards derived from OpenNeuro (30K subjects, 837 studies, 1,300 tasks)

- Training and evaluation code and model weights for the foundation model are publicly released

- Native space and minimal preprocessing steps do not substantially impact downstream FM performance

🔗 Resources:

- [Original post](https://x.com/humanscotti/status/2125675902952693871)

### 🤖 Perplexity Time Machine launches, roll index to any date

Perplexity Time Machine lets you roll the web index back to any date and search the web as it was then. It enables backtesting, reproducible evaluations, agent session replay, and checking historic page content. Training with glm-5.3 flash showed ~90% of rollout groups had zero gradient on the live web, while with Time Machine the agent learned to research and outperformed the market.

Key Points:

- **Launch**: Time Machine for the Perplexity Search and Context APIs shows a model the web as it was on a chosen date.

- **Result**: With Time Machine the agent learns to research and reason, outperforming the market, whereas on the live web ~90% of rollout groups have zero gradient.
