### 🤖 frax.ik high-performance humanoid retargeting library announced, >100k FPS

frax.ik is a new CPU-only library for humanoid retargeting and inverse kinematics that runs in low microseconds. It claims orders-of-magnitude speedup over existing alternatives and avoids foot skidding, floor penetration, and self-collisions. The accompanying frax release reports IK pipelines achieving over 100,000 frames per second.

Key Points:

### 🤖 PyTorch MoE grouped execution reduces kernel launches

PyTorch operations can be performance optimized for MoE models by grouping expert execution to cut kernel launches. The Nvidia blog uses biological foundation models as an example of efficient MoE training.

Key Points:

- **Replacement**: MoE models replace a single dense feed-forward block with multiple expert networks.

- **Optimization**: Grouped execution submits all expert work together, reducing launch and scheduling overhead.
