### 🤖 Muse Ember launch – smallest model, $0.10 per input million

Muse Ember is Meta’s smallest and most efficient model, now available on the API at $0.10 per million input tokens and $0.50 per million output tokens. It targets repeatable agent tasks such as tool calls, coding subtasks, routing, extraction, and long document parsing. The model offers a 1M-token context window and up to 512K output tokens. It claims more intelligence per dollar than Claude Haiku or GPT Luna.

Key Points:

- **Pricing**: $0.10 per million input tokens, $0.50 per million output tokens.

- **Context**: 1M-token context window, up to 512K output tokens.
