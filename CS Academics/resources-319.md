### 🤖 Qwen3.8-27B harness adapter release improves SWE-Bench Pro pass@1 to 63%

Qwen3.8-27B harness adapter for Pi harness is released as a LoRA adapter. It raises SWE-Bench Pro (Hard 51 subset) pass@1 from 29% to 63% and Terminal-Bench 2.1 pass@1 from 40% to 56%. It also reduces tool calls per task by 55-62%. More harness adapters are promised soon.

Key Points:

- **Release**: LoRA adapter for Qwen3.8-27B on Pi harness

- SWE-Bench Pro (Hard 51) pass@1 improves from 29% to 63%

### 🤖 Perturbing Inputs Improves Pretraining Distillation

Perturbing Inputs Improves Pretraining Distillation shows that adding noise to token inputs for the early part of training improves a small student LM’s ability to match a larger teacher’s next-token predictions. After that phase the models switch back to clean text and, with the same steps and token budget, it beats standard distillation and works well in data-constrained, multi-epoch settings.

Key Points:

- **Early phase**: both teacher and student read a perturbed version of the text.

- **Later phase**: switch back to clean text; same steps and token budget outperform standard distillation and perform well in data-constrained, multi-epoch settings.
