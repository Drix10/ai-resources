### 🤖 GitHub CSS Modules migration cuts render time 55% and speeds init 25%

GitHub.com has fully moved off CSS-in-JS to CSS Modules. The change yields 55% less server-side render time. Component initialization is 25% faster.

Key Points:

- **Migration**: fully moved off CSS-in-JS to CSS Modules

- **Performance**: 55% less server-side render time and 25% faster component init
