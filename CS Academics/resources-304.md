### 🤖 Otari hackathon at MozFest runs Oct 28-Nov 11

Otari hackathon at MozFest runs Oct 28-Nov 11, offering $1,000 prize and $20 token for first 200 sign-ups. Build with Otari open-source platform using any model; winners receive engineer mentoring.

Key Points:

- **Dates**: Oct. 28 to Nov. 11.

- **First prize**: $1,000 plus engineer mentoring.

- First 200 sign-ups receive $20 in tokens.

### 🤖 Airtable Omni 2.0 launch on all plans

Airtable Omni 2.0 is now available on every Airtable plan, handling messy spreadsheets and PDFs to build a working base. It can configure automations from a single sentence and answer feedback-data queries.

Key Points:

- Imports any file type, including spreadsheets, images, PDFs, and builds the data model in one pass.

- Configures complex automations from plain language and can write scripts for automation steps.

- [Original post](https://x.com/airtable/status/2114738906562232629)
