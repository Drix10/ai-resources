### 🤖 4DAnyone creates 4D humans from single video, Turbo checkpoint 27 s per 121-frame

4DAnyone generates multiview videos and 4D Gaussian Splatting from casual monocular footage, with a Turbo checkpoint that runs in about 27 seconds for a 121-frame clip on an RTX 4090. The system uses a 3D skeleton as geometric reference and introduces Reference Context Packing and Target Context Routing for consistency.

Key Points:

- 22GB peak CUDA memory for video generation on RTX 4090.

- Turbo mode is 5.58× faster than the Base version, using four denoising steps.
