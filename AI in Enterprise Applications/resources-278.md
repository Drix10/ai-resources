### 🤖 n8n Public API rate limits added in 2.47.0

n8n public API rate limits are now in n8n, letting admins cap how many requests each API key makes. The feature is available on every plan, Cloud and self-hosted, starting with version 2.47.0.

Key Points:

- Public API rate limits are now in n8n.

- Admins can cap how many requests each API key makes.

- Available on every plan, Cloud and self-hosted.

- From version 2.47.0.

- [Original post](https://x.com/n8n_io/status/2125193977976467613)
- [Rate limits Connect n8n Docs](https://docs.n8n.io/connect/n8n-api/rate-limits) - Linked page

### 🤖 Notis AI chief of staff – announced as assistant that handles briefs, prep, follow-ups

Notis positions its AI chief of staff as an assistant that runs your operating rhythm, delivering morning briefs, meeting preparation, follow-through and open-loop tracking. It claims the role differs from an AI executive assistant by acting before you ask. The page outlines three ways to obtain one: build with context files, assemble a stack of automation tools, or use Notis’s integrated assistant with memory and triggers.

Key Points:

- **AI chief of staff runs operating rhythm**: briefs, meeting prep, follow-ups, open-loop tracking.

- **Options to get one**: DIY context files, automation stack, or Notis’s assistant with built-in memory and scheduled runs.
