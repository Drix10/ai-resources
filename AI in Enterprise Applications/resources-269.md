### 🤖 Claude memory dreaming helps organize experience, improves CL-Bench results

Claude uses a “dreaming” process to reorganize logs during idle time, fixing mistakes and creating memory notes. In CL-Bench 1.0, Claude Opus 5 closed the learning loop with rule-based memory entries and matched the performance of Opus 5.5 and Sonnet 5.5.

Key Points:

- Dreaming reflects on session logs in idle compute to produce new notes and representations.

- Claude Opus 5’s memory directory contained rules, evidence of truth, prior answers, and warnings, achieving loop closure and comparable scores to Opus 5.5 and Sonnet 5.5.
