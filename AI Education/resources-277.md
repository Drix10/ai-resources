### 🤖 Descript Updates: Animate Text, Layouts, Search, and Skills

Descript adds four features—Animate Text, Generative Layouts, media Search, and Underlord Skills—to reduce the number of tabs needed for video editing. Animate Text lets users select script text and apply kinetic typography styles. Generative Layouts create brand-consistent title and overlay packs from guidelines. Search finds clips across projects by phrase; Enterprise adds visual search. Underlord Skills let users save edits as reusable skills.

Key Points:

- Animate Text (kinetic typography) selects script text, picks a style, and AI animates emphasis words as editable text layers.

- Generative Layouts generate a layout pack from brand guidelines, logos, and colors for titles, overlays, and lower thirds.
