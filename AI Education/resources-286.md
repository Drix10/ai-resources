### 📊 Quantum contextuality measured on up to 105 qubits

Quantum contextuality measured on up to 105 qubits, with 98.3% win rate in the magic square game. The work demonstrates contextuality as a benchmark and reports a Bell–Kochen–Specker inequality value exceeding the classical limit.

Key Points:

- Magic square game win rate 0.9830 ± 0.0001 across 100,000 runs per version on a 105-qubit processor.

- Measured χ value can reach 6, while any non-contextual model must satisfy χ ≤ 4.
