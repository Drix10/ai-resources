### 🤖 Claude creates 4K Blender film, 12.5k lines, $20 GPU

Claude built a 2-minute 4K Blender film from one prompt using 12,500 lines of Python code. The project rendered 3,220 frames on 89 rented GPUs for just over $20. It generated five characters, seven full sets, and 52 shots with 36 GPUs running concurrently.

Key Points:

- **Code**: 12,500 lines of Python created all assets, sets, camera moves and animation.

- **Compute**: 89 GPUs rented via RunPod rendered 3,220 frames, 36 GPUs running at once, total cost a little over $20.
