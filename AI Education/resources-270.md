### 🤖 Muse Spark Open open-sourced, 816B params, 42B active MoE

Muse Spark Open is now open-source from Meta with 816B parameters and 42B active parameters via a mixture-of-experts. It can be self-hosted without API dependency or third-party token usage.

Key Points:

- **Parameters**: 816B total

- **Active MoE parameters**: 42B

- No API dependency, self-hostable on own infrastructure

### 🤖 REA released as MIT-licensed open source tool

REA (Reverse Engineer Anything) released as an MIT-licensed open source tool that turns AI coding agents into reverse-engineering machines. It can point at any codebase to generate architecture diagrams, dependency maps, and security audits, and claims M&A due diligence in days, not months.

Key Points:

- **Release**: REA just dropped

- **License**: MIT license, open source

- **Due Diligence**: M&A due diligence in days, not months

### 🤖 Blackbox agent check between intent and action announced

Blackbox agent is the check between intent and action, built on origin_trail. It aims to add a safety layer for AI agents that run commands, install packages, and open files on trust.

Key Points:

- Agent Blackbox is the check between intent and action.
