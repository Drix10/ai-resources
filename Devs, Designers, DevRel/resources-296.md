### 🤖 Qwen3-TTS custom voice blending with 1.7B models

Qwen3-TTS lets you clone a voice from a short recording and blend it with a voice generated from a text description using the 1.7B-VoiceDesign model. The base model provides a 2048-dimensional speaker embedding that can be arithmetic-combined to create new voices. The author demonstrated blending a 28-second clip of his own voice with a designed voice and baking the result into a new reference file.

Key Points:

- 1.7B-Base clones a voice from a few seconds of reference audio using a 2048-number speaker embedding.

- 1.7B-VoiceDesign creates a voice from a text description and can be blended with a cloned embedding.
