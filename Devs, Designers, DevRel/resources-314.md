### 🤖 AWS F2 FPGA LLM inference engine 213 tps using AI agents

AWS F2 FPGA LLM inference engine reached 213.13 tps after AI agents wrote and optimized Verilog and C++. The experiment used ~3M lines of generated code, ~30M lines of output analysis, and $10k in AI API tokens.

Key Points:

- Initial implementation achieved 6.43 tps, final implementation 213.13 tps (33.13× faster).

- Experiment cost $1.98/hour for the FPGA instance; hardware was an AWS F2 FPGA with 16GB HBM.
