### 🚀 AWS Lambda Web Functions announced native HTTP support

AWS Lambda Web Functions provides native HTTP handling, allowing standard Node.js servers to run on Lambda without adapters. It runs code that listens on a port, supports up to 128 concurrent requests per environment, and can be deployed with a single CLI command that returns a live HTTPS URL in under a minute.

Key Points:

- Up to 128 concurrent requests per execution environment.

- Deploy with aws lambda‑web deploy and receive a live HTTPS URL in under a minute.

### 🤖 Kody git push concurrency queue handles 20 agents

Kody now handles git push concurrency with a queue managed in a durable object, supporting 20 agents pushing to 20 branches. When 20 agents push to the same branch simultaneously, some had to rebase and manage conflicts, but all landed.

Key Points:

- Concurrency managed by a queue in a durable object.

- 20 agents to the same branch required rebase/conflicts, all pushes landed.
