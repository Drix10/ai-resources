### 🚀 parquet-rs bloom filter improvement adopted by ClickHouse

parquet-rs bloom filter improvement is now used in ClickHouse. The change was merged via pull requests in both projects.

Key Points:

- Pull request #9628 adds bloom filter folding to parquet-rs.
