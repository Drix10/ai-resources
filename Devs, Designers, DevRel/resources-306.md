### 🤖 CompositionFilledButtonStyle static factory added for dot-completion

CompositionFilledButtonStyle now has a static factory that returns a strongly-typed instance via dot-completion. The factory creates the default button style with preset colour, size, and icon parameters. More complex styles can be built by configuring all properties in the ButtonStyle initializer.

Key Points:

- Static factory provides strongly-typed dot-completion for ButtonStyle instances

- Default style initializes CompositionFilledButtonStyle with default colour, size, and icon parameters
