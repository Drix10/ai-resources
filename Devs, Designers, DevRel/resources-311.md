### 🚀 Anthropic IPO raises $81.3B, ticker ANT on Nasdaq

Anthropic IPO raises $81.3B, ticker ANT on Nasdaq, priced at $83 per share and opened at $111.50. Run rate was about $9B at end-2025 and H1 2026 revenue was $16.3B.

Key Points:

- IPO price $83 per share, upsized to about 980M shares, raised $81.3B.

- Opened at $111.50, about 34% over IPO price, fully diluted value near $2T.

### 🚀 Reanimated 4.8.0 – Shared Element Transitions stable and default

Reanimated 4.8.0 introduces stable Shared Element Transitions that are enabled by default and can be used in any scope or navigator. A new Shared Transition API adds a fadeContent modifier to fade shared view children during transitions.

Key Points:

- Shared Element Transitions are stable and enabled by default in Reanimated 4.8.0.

- The Shared Transition API includes a fadeContent modifier that fades children out on the source view and in on the target view.
