### 🤖 WhatsApp message scheduling launches, texts/images up to 2 weeks

WhatsApp is rolling out message scheduling, allowing texts and images to be sent up to two weeks in advance. The feature arrives after long user demand.

Key Points:

- Message scheduling rollout for WhatsApp

- Supports texts and images only, up to 2 weeks ahead

### 🤖 Figure Helix zero-shot autonomous demo shows limitation

Figure Helix runs zero-shot and fully autonomous, but moving the table stops it from picking up the apple. A quoted tweet notes the robot fails when the table is moved after the command.

Key Points:

- Helix run is zero-shot and fully autonomous.

- If you move the table after asking “Go pick up an apple,” it won’t be able to pick up the apple.

- [Original post](https://x.com/edinsoncode/status/2125186425016697331)
