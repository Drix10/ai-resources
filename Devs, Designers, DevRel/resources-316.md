### 📊 Claude model reduces GRH Lean proof lines to <300K

Claude model reduced the Lean formalisation of the GRH proof from 17.4M lines to under 300K lines. The effort was done by a non-expert group in five days using the same model as Levent. The result suggests a large simplification compared with academic formalisation attempts.

Key Points:

- **Reduction**: proof size cut from 17.4M lines to <300K lines.

- **Timeline**: non-experts achieved this reduction in 5 days using the Anthropic model.
