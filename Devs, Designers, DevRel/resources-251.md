### 🤖 AI Classification - pi.dev Integration

This article describes how pi.dev users can implement AI classification using external models. It focuses on integrating models like Deepseek or Sol for data processing.

Key Points:

• pi.dev platform supports custom classification tasks.

• Deepseek is an option for classification model integration.

• Sol models offer an alternative for classification functionalities.

🚀 Implementation:
1. Utilize the pi-rou tool for integration on pi.dev.
2. Select a classification model such as Deepseek.
3. Alternatively, integrate a Sol model for classification tasks.

🔗 Resources:
• [pi-rou](https://github.com/ygncode/pi-rou) - GitHub tool for pi.dev classification.
