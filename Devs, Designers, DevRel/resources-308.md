### 🤖 Haru-4B open voice model launches with 65 ms latency

Haru-4B is an open voice model that can listen and talk simultaneously, like a phone call, with about 65 ms latency on a MacBook. It learned backchannels, interruptions and turn-taking from real conversations, and a short voice clip sets its sound.

Key Points:

- Simultaneous listen-and-talk capability, like a phone call

- Learned backchannels, interruptions and turn-taking from real conversations

- About 65 ms latency on a MacBook

### 🤖 Kimi K3.1 Pro adds architecture diagram, wiki pages, code tours, line-cited answers

Kimi K3.1 Pro from @nebiustf lets you paste any GitHub link or add a local codebase folder and generates an architecture diagram in layers, a wiki page for every module, step-by-step code tours, and answers that cite the exact lines. The tool combines GitDiagram, DeepWiki, CodeTour and CodeViz in one open-source app and runs on your own API key.

Key Points:

- Paste any GitHub link or add local codebase folder to get architecture diagram, wiki pages, code tours, and line-cited answers.

- Combines GitDiagram, DeepWiki, CodeTour and CodeViz in a single open-source application.
