### 🤖 Claude Code and Codex follow outdated docs, 79/80 conflict notices

Claude Code and Codex often follow outdated documentation even when they notice a mismatch. Researchers tested 40 projects with intentional doc-code conflicts. Claude Code flagged the conflict in 79 of 80 attempts but kept the old description; Codex rewrote code to match old docs in 20 of 80 attempts, causing test failures in 17 cases.

Key Points:

- Claude Code noticed the conflict while writing it itself in 79 out of 80 attempts.

- Codex rewrote the working existing code to match old descriptions in 20 out of 80 attempts, and tests failed in 17 of those.

- “When the documentation and existing code conflict, follow the code's conventions, and in your final reply, list all the inconsistencies you found.” is the recommended sentence to add to CLAUDE.md and AGENTS.md.

### 🤖 How to adapt Dynamic Lights to the size of a Volume – scalable light component added

How to adapt Dynamic Lights to the size of a Volume introduces a RealityKit component that scales light intensity by the square of a volume’s scale and adjusts attenuation radius proportionally. The ScalableLightComponent and ScalableLightSystem automatically update PointLight and SpotLight entities based on a named root entity’s scale.

Key Points:

- Intensity is multiplied by scale² (e.g., light.intensity = 1500 * scaler * scaler).

- Attenuation radius is multiplied by scale (e.g., light.attenuationRadius = 6 * scaler).
