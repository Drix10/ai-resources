### 🤖 AI-assisted 3D - Blender to Vision Pro Workflow

This article outlines a workflow for generating 3D models using AI, exporting them from Blender, and viewing them on Apple Vision Pro.

Key Points:

• Blender models can be created from scratch using Claude Opus 5 and reference images.

• USDZ is the export format from Blender for viewing on Vision Pro.

• Models are transferred to Vision Pro using Airdrop.

• An iterative process with AI allows for refining visual aspects.

🚀 Implementation:
1. Generate a Blender model using Claude Opus 5 by providing reference images.
2. Export the completed model from Blender as a USDZ file.
3. Transfer the USDZ file to Vision Pro using the Airdrop protocol.
4. Review the model on Vision Pro for visual issues and provide feedback to Claude for further iterations.
