### 🚀 Kubai Icons dynamic icon library released with 2.8k+ icons

Kubai Icons dynamic icon library is now available. It includes over 2.8k icons, is MIT licensed, free and open source, and offers AI-generated icons via Skills. Contributions are welcomed with credit.

Key Points:

- **Release**: Kubai Icons dynamic icon library with 2.8k+ icons.

- **License**: MIT, free and open source.

- **Feature**: AI generation of icons using Skills for consistent style.

- **Contributions**: Accepted with credit and thanks.

### 🤖 PlayCanvas digital rain shader for 3D Gaussian splats

PlayCanvas released a new shader effect called digital rain for 3D Gaussian splats, with splats turning into camera-facing glyphs lit by falling drops. The effect is open source, implemented in a single script, and runs on WebGL2 and WebGPU.

Key Points:

- **Shader effect**: digital rain for 3D Gaussian splats.

- Open source, one script implementation.

- Runs on WebGL2 and WebGPU.

### 🤖 AnimGenOffline early result shows AI-guided Metahuman animation in preview 1

AnimGenOffline, a new plugin in UE 5.9 preview 1, lets users guide Metahuman animation with high-level prompts and generates frames via AI. An early demo used the prompt “actress gets up at frame X and walks to the door, opens it at frame Y”.

Key Points:

- **Prompt blocking example**: “actress gets up at frame X and walks to the door, opens it at frame Y”.

- Plugin integrates AI-generated animation frames into Sequencer.
