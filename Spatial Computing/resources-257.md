### 🤖 MapAnything launches universal metric 3D reconstruction model supporting 12+ tasks

MapAnything introduces a single transformer model that handles over 12 metric 3D reconstruction tasks, including multi-image reconstruction, monocular depth, registration, and depth completion. The framework offers a shared interface with consistent output formats for points, depth, camera transforms, and confidence. A Hugging Face browser demo is available for immediate testing without local installation.

Key Points:

- Supports over 12 different 3D reconstruction tasks with one model.

- Provides a unified output format for points, depth, camera transforms, and confidence.

- Hugging Face browser demo can be tried without installing anything locally.
