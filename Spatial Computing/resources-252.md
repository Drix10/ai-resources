### 🤖 GPT-Live-1.1 released via API with standby cost $0.02/min

GPT-Live-1.1 is OpenAI’s speech model now available through API starting October 15. It offers consistent natural accents across languages, better letter and number recognition, and a standby mode costing $0.02 per minute.

Key Points:

- **Release date**: API access begins October 15.

- **Standby cost**: $0.02 per minute (normally $0.05).

- **Feature**: Consistent, natural accents across languages.

- **Feature**: More accurate recognition of letters and numbers.

### 🤖 China 3D reconstruction model real-time 20 FPS

China open-sourced a model that reconstructs any scene in 3D from a regular video at ~20 FPS on a single GPU. It runs with one camera, no LiDAR, stays stable over 10,000+ frames and outperforms optimization-based methods on benchmarks.

Key Points:

- **Real-time performance**: ~20 FPS on a single GPU

- **Stability**: stays stable across 10,000+ frames

### 📊 HumanCalib estimates camera pose, 0.84° error

HumanCalib calculates camera placement, real-world scale, and vertical axis from synchronized video, intrinsics, and height. It achieved a median rotation error of 0.84° across 97 trials on 5 public datasets with zero failures using MeTRAbs.

Key Points:

- **Median camera rotation error**: 0.84 degrees

- Validated on 97 trials across 5 public datasets with zero failures using MeTRAbs

🔗 Resources:

- [Original post](https://x.com/tokufxug/status/2123596962138325008)

### 🤖 SplatLab edit 3DGS objects individually

SplatLab can edit 3DGS objects individually, identifying object boundaries and filling hidden geometry. It also adds new light sources and measures wall and object dimensions.

Key Points:

- AI identifies objects and uses geometric information to determine their boundaries

- After moving or removing furniture, it fills in previously hidden floors and walls

- Supports adding new light sources and measuring the dimensions of walls and objects
